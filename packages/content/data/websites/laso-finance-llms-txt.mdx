# Laso Finance

Laso Finance lets people and AI agents spend stablecoins in the real world. Users fund an account with USDC and use it to order single-load and reloadable prepaid cards, buy gift cards, push funds to a debit card, send Venmo and PayPal payouts, and make bank payments. Agents call a payment-gated x402 HTTP API or the same capabilities as MCP tools; people use the web dashboard and the mobile app.

## Key Focus Areas

- Prepaid cards and gift cards funded with USDC
- Push-to-card, Venmo, PayPal, and bank payouts
- x402 payment-gated API for AI agents
- MCP tools for agent clients

## About llms.txt Implementation

Laso's llms.txt summarizes the product, links the API reference, OpenAPI spec, and SKILL.md, and lists every agent-callable endpoint with its price. The llms-full.txt contains the full agent documentation, including request and response shapes for each endpoint. Both carry a content-hash docs version so agents can detect a stale cached copy.
