# AmpleRun

AmpleRun is a GPU rental marketplace. You rent GPUs from independent hosts, billed per second from verified readiness, and pay from a prepaid USDC or USDT balance on Base. One flat 5% fee is inside every rate.

## Key Focus Areas

- **Agents as customers**: a hosted MCP server at `https://amplerun.com/api/mcp` and a REST API described by an OpenAPI document.
- **Agent sign-up**: an agent opens its own account with a wallet signature (EIP-4361), no email.
- **x402 top-ups**: the prepaid balance can be topped up over x402 (USDC on Base).
- **Hosting**: a one-line installer lists a Linux machine's NVIDIA GPU after its owner approves it.
