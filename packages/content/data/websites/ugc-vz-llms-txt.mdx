# UGC VZ

Free, commission-free directory of real UGC creators in Germany, Austria and Switzerland, searchable by brands and AI agents.

## Key Focus Areas

- Creator profiles with portfolio links, social proof and self-reported rates
- Contact requests from brands, delivered by e-mail
- Public REST API (OpenAPI) and a remote MCP server for agents

## About llms.txt Implementation

UGC VZ publishes an `llms.txt` file that describes the directory, how brands request creator contacts, and where the API and MCP documentation live.
