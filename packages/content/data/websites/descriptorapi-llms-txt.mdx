# DescriptorAPI

Turn messy card transaction descriptors from any bank into clean merchant data: name, category, website, location, processor and a confidence score\.

## Key Focus Areas

- **Transaction Enrichment**: Turns raw card statement lines into clean merchant data: name, category, website, location, payment processor and a confidence score
- **Global Coverage**: Reads descriptors from banks in any country, including Arabic script, with deep coverage of the UAE and Egypt
- **Processor Awareness**: Recognises payment facilitator prefixes such as SQ \*, PAYPAL \*, Paymob, Geidea and Tabby to find the real merchant behind them
- **Non-Purchase Lines**: Tells purchases apart from transfers, refunds, fees and declines

## About llms.txt Implementation

Our llms.txt points AI assistants to the API documentation, the OpenAPI specification, a ready-made integration prompt for coding assistants, pricing, and a library of guides on how card descriptors work.

## Features

- **REST API**: Documented endpoints with a full OpenAPI specification
- **Playground**: Decode a statement line in the browser, no signup needed
- **AI Integration Prompt**: Paste-ready instructions so coding assistants can integrate the API quickly
- **Merchant Directory**: Merchants verified by the DescriptorAPI team
