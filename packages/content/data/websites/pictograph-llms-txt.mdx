# Pictograph

Pictograph is a computer vision platform for AI agents and developers. SAM3 drafts image labels from a point, a box or a text prompt; you review them, then train a small task-specific model (RF-DETR, YOLOX, Segformer) on managed GPUs and deploy it as a TensorRT endpoint that takes single images or live RTSP and WebRTC video, with results for every frame. A CLI where every command takes `--json`, a Python SDK and a Claude Code skill let coding agents run the whole loop and call trained models as tools. Every docs page has a markdown twin at its URL plus `.md`.
