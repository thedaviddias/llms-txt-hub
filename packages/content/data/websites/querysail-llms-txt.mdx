# QuerySail

QuerySail runs hosted MCP servers that connect ChatGPT, Claude, Codex and Cursor to the accounts behind your website, starting with Google Search Console\.

## Key Focus Areas

- **Google Search Console MCP server**: clicks, impressions, CTR and position by query, page, country, device or date, period comparisons, URL inspection and sitemap status, asked in plain language.
- **Hosted, no setup**: one remote MCP endpoint with OAuth sign-in; nothing to install and no API keys.
- **Works across clients**: ChatGPT, Claude, Codex, Cursor, VS Code and other MCP clients.
