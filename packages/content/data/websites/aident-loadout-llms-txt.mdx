# Aident Loadout

Aident Loadout connects Codex, Claude Code, Cursor, ChatGPT and other MCP clients to 1,000\+ apps and 400\+ expert\-built Skills through one setup, with credentials in Aident Vault and every action logged in Audit\.

## Key Focus Areas

- **One setup for every agent**: Connect apps once and reuse them across Codex, Claude Code, Cursor, ChatGPT, Claude Desktop and other MCP clients.
- **Remote MCP server**: Streamable HTTP endpoint at `https://loadout.aident.ai/mcp` with OAuth sign-in; a CLI (`@aident-ai/cli`) and an MIT-licensed agent Skill are also available.
- **Vault and Audit**: API keys and delegated credentials stay in Aident Vault; Audit records what ran, from which agent, whether it succeeded and what it cost.
