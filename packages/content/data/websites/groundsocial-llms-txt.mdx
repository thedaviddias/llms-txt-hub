# Groundsocial

Groundsocial is one API for public social and web data. A single key and credit balance return posts, comments, profiles, transcripts and search results from 77 platforms, including Reddit, X, TikTok, Instagram, YouTube, LinkedIn, Bluesky, Hacker News, Google Search and Amazon, each in the platform's own JSON shape. It is available as a REST API with an OpenAPI spec and as a remote MCP server.

## Key Focus Areas

- Social data API (Reddit, X, TikTok, Instagram, YouTube, LinkedIn)
- Remote MCP server for AI agents
- Search engine results and web pages as Markdown
- Pay-per-call credits with refunds on failed calls

## About llms.txt Implementation

Groundsocial's llms.txt lists every platform with its status and coverage, points agents to the free platform list and the SKILL.md for self-signup, and links the Markdown version of every docs page. The llms-full.txt contains the full docs in one file.
