# Sablebolt

Account-free crypto swaps between two addresses: routes, coins, fees and agent tools, as plain text for language models.

## Key Focus Areas

- Crypto swaps without an account
- Routes, coins, limits and network fees
- MCP server, OpenAPI and an A2A agent card for AI agents

## About llms.txt Implementation

Sablebolt provides an `llms.txt` file that lists its routes, coin guides and posts, and points to the MCP endpoint, the OpenAPI file and the agent card; every page also has a markdown twin at its own path plus `.md`.
