# ParlayAPI

ParlayAPI provides sports odds and player props through a REST API and a locally run MCP server. Account data uses the reader's own API key, with free monthly credits and paid plans.

## About llms.txt

The public manifest links API documentation, authentication and credit guidance, source coverage, MCP setup and language quickstarts. Availability varies by sport, bookmaker, market and date.
