# Zovo MCP Servers

Zovo MCP Servers is a catalogue of Model Context Protocol servers for office work: invoices, expenses, time tracking, Word documents, spreadsheets, currency rates and time zone planning. Most servers answer at a hosted endpoint, and .mcpb bundles for Claude Desktop are also available.

## About the llms.txt Implementation

`llms.txt` lists each server with its page under `mcp.zovo.one/s/`, what it does, its free tier limits, and whether it has a hosted endpoint or is bundle only. It also tells assistants how to get a connection token. `llms-full.txt` serves the expanded version of the same catalogue.

## Coverage

- One entry per server, with a link to its documentation page
- Free tier limits and the one-time Pro licence for each server
- Connection notes: hosted endpoint, token setup and .mcpb bundle downloads
