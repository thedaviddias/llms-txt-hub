# Dauntless Agent Directory

A free, read-only pilot catalog of services for AI agents. Service records expose authentication requirements, provider documentation, limitations, and scoped observations where available. The catalog is available as HTML and JSON, with an OpenAPI description and a compact agent guide.

The pilot contains eight services and three recorded checks. Unknown requirements remain unknown; a listing is not an endorsement or a general safety guarantee. No account, API key, or payment is required to read the directory. Listed providers have their own prerequisites.
