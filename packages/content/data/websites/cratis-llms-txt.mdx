# Cratis

Cratis is an open-source, MIT-licensed platform for building event-sourced and CQRS applications. At its center is Chronicle, an event sourcing database and processing runtime with a .NET SDK and TypeScript, Kotlin/Java and Elixir clients. Arc is an opinionated CQRS application framework for ASP.NET Core with commands, queries, validation, authorization and generated TypeScript proxies.

## Key Focus Areas

- Event Sourcing
- CQRS Application Frameworks
- Event Modeling
- Developer Tooling
