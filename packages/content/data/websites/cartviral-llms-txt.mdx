# CartViral

CartViral is an AI content engine for online sellers. A seller pastes a product or store link (Shopify, Amazon, Etsy or their own site) or uploads photos, and CartViral makes vertical TikTok, Reels and Shorts videos, product photos, social carousels, static ads and listing copy from the real product photos and copy. It never posts for the seller. A free start gives 18 credits with no card. CartViral also has an MCP server and a REST API for AI agents.

## Key Focus Areas

- AI product videos for TikTok, Instagram Reels and YouTube Shorts
- Product photos, carousels and static ads for e-commerce
- MCP server and REST API for AI agents
- Creator marketplace that pays commission per confirmed sale

## About llms.txt Implementation

CartViral's llms.txt tells AI assistants how to connect the CartViral MCP server, what each product costs in credits, the current plans and prices, and links every guide, academy lesson and free tool page. The llms-full.txt carries the full text of those pages, and a plain-text pricing page lives at https://cartviral.com/pricing.md.
