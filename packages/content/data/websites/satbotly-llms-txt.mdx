# SatBotly

SatBotly is a free, source-checked directory of what AI agents can pay for on their own with Bitcoin, Lightning, L402, x402, Cashu, MPP or stablecoins. Every verdict (YES, KINDA, NO) links to a quote copied from its source page.

## Key Focus Areas

- Agent payment services and tools checked with source quotes
- Agent wallet leaderboard scored by verified features (MCP, SDK, spend controls, self-custody)
- Pay-per-call APIs (L402, x402, MPP) priced from their unpaid HTTP 402 challenge
- Public CC BY 4.0 JSON datasets and a free lookup API (`GET /api/v1/lookup`, OpenAPI 3.1)

## About llms.txt Implementation

SatBotly's `llms.txt` summarizes how verdicts and 402 prices are sourced and lists all main directory pages, raw JSON dataset URLs (`/data/*.json`), and the OpenAPI specification (`/openapi.json`).
