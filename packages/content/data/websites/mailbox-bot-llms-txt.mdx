# mailbox.bot

mailbox.bot is a postal mail API and MCP server for AI agents: letters, postcards and certified mail, with webhooks, cost caps and human approval. Agent mailboxes are live now: a street address + PMB at the staffed, USPS-compliant Manhattan Beach, CA facility, where staff log each letter and package and carry out scan, forward or discard once a human approves.
