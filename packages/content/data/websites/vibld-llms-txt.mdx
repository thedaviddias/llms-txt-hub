# vibld

vibld (pronounced "vibe-build") is an AI application builder from Chris Brock LLC. A conversation becomes a working project, and the generated application is a conventional, portable software project that keeps working without vibld. It is in public beta.

## Key Focus Areas

- Generated code meant to be readable enough to review, not merely exportable
- Export the complete project, or push it to GitHub as a branch and a pull request
- Each project's history kept as revisions
- An open-source path to run the same bounded build locally with your own model key

## About llms.txt Implementation

vibld's llms.txt describes what the product is (and that it is unrelated to Bible study software), its beta status, where to sign up, and how to run the open-source generator from a clone of github.com/vibld/vibld.
