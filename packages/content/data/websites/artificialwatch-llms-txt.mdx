# ArtificialWatch

ArtificialWatch checks the AI labs' own APIs every 60 seconds and confirms each new model on a second sweep before it alerts subscribers by email, Chrome push, text or phone call. It also publishes a public track record of every launch call, live model status checks, a daily benchmark index and a feed of model-release signals.

## Key Focus Areas

- New AI model release detection
- Model availability and status checks
- Public track record of first sightings
- Open benchmark and coding index data (JSON and CSV, CC BY 4.0)

## About llms.txt Implementation

ArtificialWatch's llms.txt explains how detection works and what each plan includes, then links every key page: the radar, the track record, the per-lab status pages, the Bench Index, LLM API pricing, the Wire, head-to-head model comparisons and the open data files.
