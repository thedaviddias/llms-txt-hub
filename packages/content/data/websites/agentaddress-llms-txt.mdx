# AgentAddress

Persistent webhooks, HTTP callback queues, and an email inbox for AI agents. AgentAddress gives ephemeral agent runs a durable return path: a public write-only HTTPS inbox for webhooks and callbacks, a public email address for human or service replies, and a private ordered event queue that a future agent run polls with a one-time read token. Provisioned with a single unauthenticated POST, so agents can create a return address without an account. Includes a hosted MCP endpoint and an installable agent skill.
