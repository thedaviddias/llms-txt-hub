# ERDILRF Laser Rangefinder Modules

ERDILRF is the product site of ERDI TECH LTD (Chengdu, China), a manufacturer of OEM laser rangefinder modules for drones, robots, AGV, surveying and industrial measurement. Every model page lists the test condition behind its range figure, the interface, weight and a public price.

## Key Focus Areas

- Model-by-model records of 905 nm and 1535 nm laser rangefinder modules with range, accuracy, interface, weight and public price
- Machine-readable catalog API (`/wp-json/erdi/v1/catalog`) alongside a model-level `llms-full.txt`
- Open drivers for the UART protocols: Python (`pip install erdi-lrf`), Arduino, ROS 2
- Open comparison dataset of 109 modules from 8 manufacturers with source URL and capture date per row

## About llms.txt Implementation

The llms.txt lists the catalog API, the model directory, datasheets and CAD downloads, driver documentation and engineering articles. llms-full.txt carries one record per model, so an assistant can quote range, interface and price with the test condition attached.
