# Vibe Manufacturing

Playbook, open manufacturer directory and agent interfaces for turning an idea into a manufactured product with AI-written CAD.

## Key Focus Areas

- A 13-step playbook from measuring a part to scaling production, with guides, comparisons and business ideas
- A directory of contract manufacturers by country, process and city, compiled from open data and company websites, also available as open JSON
- A prototype planner: describe a hardware product, get the parts, make or buy, matched manufacturers and one quote request per part
- A remote MCP server and REST API so AI agents can plan a prototype, match a part spec to manufacturers, estimate cost and request quotes

## About llms.txt Implementation

Vibe Manufacturing publishes an `llms.txt` index and an `llms-full.txt` file containing the full editorial text, plus a methodology page that explains how the directory data is compiled and where its limits are.
