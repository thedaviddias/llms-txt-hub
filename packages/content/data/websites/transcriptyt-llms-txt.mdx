# TranscriptYT

TranscriptYT returns the transcript of any public YouTube video as JSON, plain text, SRT, VTT, CSV or Markdown in 150+ languages. It is available as a REST API, a hosted MCP server for Claude, ChatGPT, Cursor and other agents, and a free web tool. Videos without captions can be transcribed with AI.

## Key Focus Areas

- YouTube Transcript API
- MCP Server for AI Agents
- Playlist, Channel and YouTube Search Listing
- AI Transcription for Videos Without Captions

## About llms.txt Implementation

The llms.txt lists every API endpoint with its parameters and credit cost, the OpenAPI spec, SDKs (Python, LangChain, JavaScript), the MCP setup, and links to Markdown copies of the docs and guides. The llms-full.txt contains the full text of those pages.
