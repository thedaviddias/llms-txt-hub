# Orkas

Orkas is an open-source, local-first desktop AI workforce. A Commander turns goals into executable plans and coordinates specialist agents in parallel or sequence through one chat. It brings research, coding, data analysis and documents into a local desktop workspace.

Packaged installers are available for macOS and Windows; Linux can be run from source. The core app is free; model usage and optional services may cost extra.
