# HaulierScope

HaulierScope makes Great Britain operator-licence register data easier to check and compare. Its free, read-only JSON API and 15 MCP tools cover operators, licences, operating centres, weekly DVSA changes and traffic-area statistics. Responses include their source and DVSA file date. No account or API key is required for the API or MCP tools. Optional licence monitoring is available separately on the website.
