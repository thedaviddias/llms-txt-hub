# mowteng

mowteng is a remote MCP server that connects AI assistants such as Claude, ChatGPT, Gemini, Cursor and Antigravity to Google Search Console, Bing Webmaster Tools, Yandex Webmaster and IndexNow through one URL. Users add the URL and sign in with Google; search data is fetched live for each request and never stored.

## Key Focus Areas

- Search Console and Bing Webmaster data inside AI assistants
- SEO analyses: striking distance, content decay, keyword cannibalization, index audit
- Sitemap and URL submission, IndexNow pings
- Model Context Protocol (MCP) integrations
