# Benchline

Free, open-source directory of 71 browser tools for JSON, PDFs, images, tokens, headers and AI search files, each also callable through a stateless MCP server.

## Key Focus Areas

- Developer, data, SEO and AI search, image, PDF, security, design, text, math and network tools
- Most tools run entirely in the browser, so files stay on the device
- The same functions over a stateless Streamable HTTP MCP server at `/mcp` and over `POST /api/v1/tools/<slug>`

## About llms.txt Implementation

Benchline generates `llms.txt` and `llms-full.txt` from its tool registry at build time, so every tool page and its description are listed for AI readers.
