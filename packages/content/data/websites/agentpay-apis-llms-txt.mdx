# AgentPay APIs

Pay\-per\-call APIs and remote MCP servers for AI agents: web page to markdown extraction, DNS/WHOIS/IP and domain\-report lookups, PDF to text, RSS/Atom feeds to JSON, and sitemaps to URL lists\. Paid per call via x402 in USDC on Base or Algorand, or with prepaid credits\. No signup\.

## Services

- **Web Extract**: fetch any URL and get the main content as markdown, plus title, Open Graph metadata, canonical URL and outbound links.
- **Domain & Network Lookup**: DNS records over HTTPS, WHOIS via RDAP, IP network ownership with reverse DNS, and a one-call domain report (registration, DNS, email provider, SPF/DMARC, hosting).
- **Doc Tools**: per-page text from PDF URLs, RSS/Atom/JSON feeds normalized to JSON items, and sitemap crawling (via robots.txt) into URL lists.

## Access

Each endpoint is available as a REST API (with an OpenAPI spec) and as a Streamable HTTP MCP server. Calls are paid with standard x402 v2 or with prepaid credit API keys; invalid input is rejected before payment.
