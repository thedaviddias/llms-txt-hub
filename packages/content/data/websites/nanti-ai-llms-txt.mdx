# nanti.ai

nanti.ai builds specialized AI agents for the Odoo ERP, native to Odoo's data model rather than a chatbot bolted on around an export. Each agent works inside the customer's Odoo, but hosting and data handling are product-specific: Nanti Sales Coach performs its local analysis in Odoo and sends a limited coaching payload to its Google Cloud service in the EU, while other products are designed to run entirely on the customer's own infrastructure.

## Key Focus Areas

- Nanti Sales Coach: an AI sales coach inside the Odoo 19 quotation screen, available now on Odoo 19
- Context Layer for Odoo: a verified runtime plus an open standard on GitHub, in early access
- Execution Layer for Odoo: makes every AI action on Odoo verified, governed, and receipted, available now on Odoo 19
- Nanti Manufacturing Planner: an AI manufacturing planner for Odoo, in development
- Odoo-native design, so the products can run on the customer's own infrastructure
