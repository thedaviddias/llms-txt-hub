# UserTold

UserTold runs consented voice interviews inside a product and keeps interview transcripts, page context, and observed behavior linked to the evidence.

## Agent access

The hosted Streamable HTTP MCP endpoint uses OAuth 2.1 with PKCE. Agents can manage Studies, inspect Interviews, and review Evidence and Findings before explicit delivery to configured Linear or GitHub destinations.
