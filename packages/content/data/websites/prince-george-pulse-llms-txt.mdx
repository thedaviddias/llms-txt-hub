# Prince George Pulse

Prince George Pulse provides local information for Prince George, British Columbia, Canada. Its llms.txt index links to public pages, developer documentation and machine-readable data for local events, businesses, weather, transit and civic services.

- [Developer documentation](https://princegeorgepulse.ca/developers/)
- [OpenAPI specification](https://princegeorgepulse.ca/api/v1/openapi.json)
- [Read-only MCP endpoint](https://princegeorgepulse.ca/mcp)

The public API and MCP endpoint require no API key. Responses include source, licence and attribution information; third-party data remains subject to its source licence.
