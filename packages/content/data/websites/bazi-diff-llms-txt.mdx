# Bazi Diff

Draw a BaZi Four Pillars chart or a Zi Wei Dou Shu natal chart without an account. The BaZi calculator can compare possible charts across a known time range. The career guide runs both systems with the same fictional date to show what each chart provides.

The public llms.txt file indexes the bilingual calculators, calculation conventions, guides and reproducible examples.
