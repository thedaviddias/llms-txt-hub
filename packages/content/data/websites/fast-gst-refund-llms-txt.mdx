# Fast GST Refund

Fast GST Refund provides public preparation guides for Indian service exporters and five free, read-only MCP tools. The tools cover preparation checklists, cited guide search and retrieval, Statement 3 and Annexure B upload-error guidance, and anonymous invoice-to-receipt allocation checks.

Connect over Streamable HTTP at `https://fastgstrefund.com/mcp` without an account or API key. Setup and scope are documented at [Fast GST Refund for agents](https://fastgstrefund.com/for-agents/).
