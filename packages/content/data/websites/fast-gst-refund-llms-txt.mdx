# Fast GST Refund

Fast GST Refund provides cited preparation guides and eleven MCP tools for Indian service-export GST refunds. Get a checklist, read the field requirements, validate export invoices and purchase records, and create Statement 3 and Annexure B JSON without the GST offline Excel utilities. Supporting tools explain upload errors and check anonymous invoice-to-receipt allocations.

Connect over Streamable HTTP at `https://fastgstrefund.com/mcp`. Guidance and validation are free and need no account. File downloads use OAuth or website sign-in and access for the GSTIN/refund period; ₹499 + GST covers both files and corrections. The taxpayer reviews and uploads the files to the GST portal. See [Fast GST Refund for agents](https://fastgstrefund.com/for-agents/) for connection and access details.
