# Kardinal Route Optimization

Route optimization API for developers and AI agents: the market’s widest constraint coverage, self\-serve\. Docs, console, 1,000 free credits, no sales call\.

## Kardinal Route Optimization API

Self-serve REST API that solves multi-stop, multi-vehicle routing problems under real operational constraints, and re-optimizes live plans without starting from scratch. Built for developers and their AI agents.

## Start here

- **llms.txt:** `https://developers.kardinal.ai/llms.txt`
- **If you are an AI agent:** read the [agent modeling checklist](https://developers.kardinal.ai/getting-started/agent-modeling-checklist.md) before writing any integration code
- [First API call](https://developers.kardinal.ai/getting-started/first-api-call.md): get a sandbox key and compute your first route
- [Complete route walkthrough](https://developers.kardinal.ai/getting-started/complete-tour-walkthrough.md): multiple vehicles, depots and time windows
- [Real-time re-optimization](https://developers.kardinal.ai/guides/real-time-reoptimization.md)
- [Limits and quotas](https://developers.kardinal.ai/reference/limits-and-quotas.md) and [changelog](https://developers.kardinal.ai/reference/changelog.md)

## Pricing

1,000 free credits (one credit = one optimized stop), then prepaid per-stop packs from €99 for 2,000 stops. Re-optimizing the same stop within 24 hours is free.
