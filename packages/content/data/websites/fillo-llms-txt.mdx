# Fillo

Fillo provides native form SDKs for React, Vue, Svelte, Astro, and browser apps.
Create forms in the editor or define them in code. Fillo handles validation,
uploads, responses, and webhooks while the app controls its UI.

The public documentation covers SDK setup, schemas, the management API, file
uploads, integrations, and the CLI and MCP server.
