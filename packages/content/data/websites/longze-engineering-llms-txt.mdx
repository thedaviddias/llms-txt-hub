# Longze Engineering

Longze Engineering is the export-facing brand of Hebei Longze Metal Products Manufacturing Co., Ltd., a fastener manufacturer in Yongnian, Handan, Hebei, China.

The site publishes:

- dimensional size charts for 16 DIN, ISO and ASME fastener standards
- mechanical property references for bolt property classes and washer hardness
- engineering calculators (container loading, tightening torque, thread and unit conversion)
- an open fastener standards dataset (872 records, CSV + JSON, CC BY 4.0): https://lz-engineering.com/open-data/

The llms.txt file lists the main sections and key pages for AI assistants.
