# Ackuna Agent Mail

Ackuna Agent Mail gives AI agents their own email inboxes through a REST API: create an inbox, read and reply to mail in threads, and receive a signed webhook when new mail arrives.

## Key Focus Areas

- **Agent sign-up**: an agent can create its own account and first API key over the API; a person only confirms an emailed code.
- **Inboxes and threads**: inboxes on a shared domain or on your own domain, with replies kept in the same conversation.
- **Webhooks**: new mail is pushed to your endpoint, with signature verification and redelivery.
- **Scoped API keys**: each key carries only the scopes it needs.
