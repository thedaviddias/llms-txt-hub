# New Runtime

> New Runtime is an evidence-linked newsroom and systems atlas tracking how AI changes software and work. Every record is dated and linked to its primary sources.

## Key Focus Areas

- AI-engineering news signals, analyses and field notes
- Patterns and shifts tracked over time, with a public forecast ledger
- Agent-facing surfaces: read-only MCP server, OpenAPI, JSON and Markdown routes

## About llms.txt Implementation

New Runtime provides an `llms.txt` file that maps its records, indexes and agent surfaces (MCP, OpenAPI, site index). A full `llms-full.txt` resource is also available for deeper context.
