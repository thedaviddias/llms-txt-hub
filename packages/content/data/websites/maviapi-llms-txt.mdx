# maviapi

The unofficial API for any website: hosted, documented JSON APIs for sites with no official API, kept working when the site changes.

## Key Focus Areas

- **Hosted JSON APIs**: each site gets documented endpoints with a published response schema, called with one key.
- **Kept working**: endpoints are monitored and repaired when the site changes.
- **Agent ready**: the whole catalog is available as MCP tools at https://mcp.maviapi.com/mcp, or locally with `npx -y @maviapi/mcp`.
- **Open contracts**: every API ships an OpenAPI 3.1 document and a Postman collection.

## About llms.txt Implementation

The llms.txt explains when to use maviapi, how agents connect through the MCP server, and links the docs, the API catalog and pricing. The llms-full.txt is generated from the live catalog and lists every API with its page, description, endpoints and their parameters in one Markdown file.
