# Latchkey

Latchkey runs managed GitHub Actions runners that diagnose and repair transient step failures mid-run, and exposes a CLI and a hosted MCP server so coding agents can run commands on fresh Linux runners, read failure bundles (root cause, failing file, logs) and fix the cause. The llms.txt covers when to use the service, the MCP endpoint and tools, the REST API (OpenAPI 3.1) and the CLI; llms-full.txt indexes the Latchkey Learn pages (CI/CD error guides and reports) with one-line summaries.
