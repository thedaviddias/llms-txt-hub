# TopxAI

TopxAI is a model API service run by TopXEA. It serves fourteen models from seven providers (Claude, GPT and GPT Image, Grok and Grok Imagine Video, a private GLM-5.3 deployment, Kimi K3, DeepSeek V4 and TypeSafe's Jev) through OpenAI- and Anthropic-compatible endpoints: Chat Completions, Responses, Messages, image and video generation and `/v1/systemone`. Every model has a fixed USD price per route, published before a key is created, on prepaid credit; prompts and completions are relayed in memory and never stored.

## Key Focus Areas

- One base URL and key for several model providers
- Fixed, published USD prices per model and route, with a live JSON price list
- Setup guides for coding agents and chat clients (Claude Code, Codex CLI, Cursor, Cline, LiteLLM, n8n and others)
- Hosted MCP servers that expose the catalogue to MCP clients

## About llms.txt Implementation

TopxAI's llms.txt lists the documentation, the per-model pricing pages, the blog and the changelog in English and Chinese, each with its one-line description, and points to the API reference and the OpenAPI document. The llms-full.txt carries the complete English text of the documentation (every docs page with its canonical URL); the pricing pages and blog posts are linked from llms.txt rather than included in it.
