# AgentReady WebSec Auditor API

AgentReady WebSec Auditor ([Zluowa/domain-ai-sec-auditor](https://github.com/Zluowa/domain-ai-sec-auditor)) is a zero-dependency Node.js 24 bulk CLI, Apify PPE Actor, and x402 v2 Base Mainnet API for auditing AI Search/GEO readiness and OWASP web security posture.

## Key Focus Areas

- `/llms.txt` & `/llms-full.txt` Detection with SPA Soft-404 Filtering
- RFC 9309 `robots.txt` Access Matrix for 12 Major AI Crawlers (GPTBot, ClaudeBot, PerplexityBot, etc.)
- OWASP HTTP Security Headers (HSTS, CSP, COOP, CORS) with Smart WAF Degradation
- TLS Certificate Health, DNS SPF/DMARC/CAA, and SSRF IP-Pinning

## About llms.txt Implementation

The `/llms.txt` endpoint provides machine-readable instructions for calling `/api/v1/audit-domain`, discovering `/.well-known/x402`, and parsing deterministic 0-100 AI-Readiness and WebSec JSON reports.
