# MCPGuard x402 API

MCPGuard is a zero-dependency Node.js security and cost gate for AI agents, available as an open-source CLI/GitHub Action/stdio MCP server ([Zluowa/mcpguard-kit](https://github.com/Zluowa/mcpguard-kit)) and a pay-per-call x402 v2 API on Base Mainnet.

## Key Focus Areas

- MCP Configuration Security Auditing & Secret Sanitization (`mcp.json` / JSONC)
- AI Agent Rules Backdoor & Context Tax Auditing (`AGENTS.md`, `CLAUDE.md`, `.cursorrules`, `SKILL.md`)
- Unicode Tag Steganography & Trojan Source Bidi Override Detection
- Runaway Token/USD Budget & Ping-Pong Loop Circuit Breakers

## About llms.txt Implementation

The `/llms.txt` endpoint documents all 5 x402 v2 pay-per-call audit routes, `/.well-known/x402`, `/openapi.json`, and deterministic JSON/SARIF 2.1.0 response formats for autonomous AI agents.
