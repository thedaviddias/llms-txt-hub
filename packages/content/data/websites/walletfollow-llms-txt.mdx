# WalletFollow

WalletFollow is a Hyperliquid wallet research platform. Its public documentation covers wallet tracking, portfolio analysis, copy portfolios, a read-only Data API and an authenticated MCP connector for compatible AI assistants.

## Public documentation

- Product pages and published plans
- Data methodology, source timestamps and historical coverage limits
- Wallet research guides, metric definitions and copy-trading risk explanations
- API authentication, request budgets and read-only MCP setup

Individual wallet results require a verified signed-in account. API and MCP access require the appropriate credentials, scopes and plan allowances. The research MCP does not execute orders, transfer funds or authorize copy trading.

## llms.txt implementation

The root llms.txt links to canonical public product pages, Markdown versions of educational guides, methodology and legal pages. The optional llms-full.txt combines the public product and educational material. These files exclude private wallet/account data and do not grant API access.
