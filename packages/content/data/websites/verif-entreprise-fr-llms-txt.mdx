# Vérif Entreprise FR

French company verification (KYB) by SIREN for AI agents, built on official open data (Annuaire des Entreprises, BODACC, ADEME)\. Paid per call in USDC via x402, with no account or API key\.

## Key Focus Areas

- **One-call company check**: legal status, insolvency-procedure state parsed from BODACC notices, and a verdict justified by documented signal codes.
- **RGE certifications**: energy-renovation qualifications of an establishment by SIRET, with validity dates.
- **Agent-ready**: HTTP API with OpenAPI 3.1 and a paid MCP server; errors are never charged.

## About llms.txt Implementation

The llms.txt file tells agents what each endpoint does, how much it costs, how to pay with x402 and how to read the verdict and signal codes.
