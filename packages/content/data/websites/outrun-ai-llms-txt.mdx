# Outrun AI

Outrun AI is a prepaid AI API. One OpenAI-compatible key reaches GPT, Claude, Gemini, Grok, DeepSeek, GLM, Kimi, Qwen and other models across text, image, video and speech, billed per use from one USD balance at a published per-token rate. The same key speaks OpenAI Chat Completions and Responses, Anthropic Messages and Gemini native formats, so coding agents such as Claude Code, Codex, Cline and OpenCode work by changing the base URL.

## Key Focus Areas

- OpenAI-compatible API gateway (base URL `https://api.outrun.to/v1`)
- Published per-model prices, also as public JSON
- Setup guides for coding agents and chat apps
- Prepaid, pay-as-you-go billing with no subscription

## About llms.txt Implementation

Outrun's llms.txt gives the key facts (base URL, supported API formats, billing model, live price feed), then links the pricing page, the model index, the API docs and a setup guide for each supported tool, with Markdown versions of the docs. The llms-full.txt contains the full text of the documentation.
