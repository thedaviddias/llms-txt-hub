# Shiliu (拾流)

Shiliu connects content creators' own AI agents to reference data, creative methods, and an API-accessible cloud workspace.

## Key capabilities

- Research benchmark creators and available source content.
- Discover creative skills for topic research, writing, and revision.
- Read and organize goals, reference notes, drafts, and preferences in cloud documents and tables.
- Discover supported external data interfaces through a public catalog.

## Agent documentation

The public Chinese-language `llms.txt` links to the Agent guide, API documentation, skill directory, workspace schema, and account connection flow. Public skill discovery is free; private workspace operations require user authorization, and data services may incur fees.
