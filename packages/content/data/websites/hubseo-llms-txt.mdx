# HubSEO

HubSEO audits one live public URL, ranks what is wrong and writes the top fix as a prompt to paste into an AI coding agent. Nothing is installed on the site.

## Key Focus Areas

- Lighthouse lab tests on mobile and desktop, with Core Web Vitals field data when Chrome has enough of it
- Crawlability, on-page signals, structured data and security headers
- One fix prompt per finding for Cursor, Claude Code, Copilot or Codex
- Free tools: an llms.txt validator, an AI crawler checker, a schema validator and a Core Web Vitals test

## About llms.txt Implementation

HubSEO provides an `llms.txt` file with AI-readable information about its product, tools and guides. A full `llms-full.txt` resource is also available with the complete page inventory.
