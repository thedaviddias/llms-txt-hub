# BulkPublish

BulkPublish is a social media scheduling and bulk-publishing tool. Users compose a post once and publish or schedule it across 15 platforms, including Facebook, Instagram, X / Twitter, TikTok, YouTube, LinkedIn, Threads, Bluesky and Pinterest. It also offers CSV import, RSS-to-post automation, analytics, a REST API and a hosted MCP server for AI agents.

## Key Focus Areas

- Cross-posting and Scheduling
- Bulk Publishing and CSV Import
- Social Media Analytics
- REST API and MCP Server for AI Agents
