# Silicon Valley Atlas

Silicon Valley Atlas (SV Atlas) is a sourced directory of accelerator-backed AI startups, their founders, funding and investors. Every fact links to the public page it came from. It reads a product's website, writes its ideal-customer profile, and ranks the startups it tracks as likely buyers.

## Key Focus Areas

- AI Startup Directory
- Founder and Investor Research
- Funding Data
- ICP-based Company Matching

## About llms.txt Implementation

SV Atlas's llms.txt says when an agent should use it and lists the tools of its remote MCP server (https://svatlas.io/mcp, OAuth sign-in). It also links the public pages, and the home page, pricing and every company profile return Markdown when requested with `Accept: text/markdown`.
