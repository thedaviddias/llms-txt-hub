# Skysay

Skysay provides voice-agent telephony, phone numbers, calls, SMS and campaigns. AI assistants can connect through its hosted Streamable HTTP MCP endpoint with OAuth or scoped API keys. Calling, messaging and provisioning may incur Skysay usage charges.

Official connection instructions: [Skysay MCP documentation](https://skysay.ai/docs/mcp).

Number availability, capabilities and verification requirements vary by country. 100+ countries covered.
