# NoctHost

NoctHost resells cloud servers from Vultr, DigitalOcean, Hetzner and Linode through one account, one prepaid balance and one REST API. Servers are billed by the hour and can be paid for with crypto or a card.

## Key Focus Areas

- Shared VPS, dedicated-CPU, bare metal, GPU and Windows servers
- One API and one balance across four clouds
- Hourly billing with a prepaid balance
- MCP server at https://mcp.nocthost.com/mcp for deploying servers from an AI assistant

## About llms.txt Implementation

The llms.txt is written as an API guide for AI agents: a step-by-step path to deploy one server, every endpoint with request and response shapes, the catalog of plans and regions, server statuses, error codes and rules for agents. The llms-full.txt adds the full documentation, plans and regions in one file.
