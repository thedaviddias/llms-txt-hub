# Torque Index

Neutral reference for 27 US truck and van engine platforms: parts fitment, failure maps, OEM part numbers, NHTSA recalls and a free VIN API.

## What Torque Index does

Torque Index is a structured reference for Ford Power Stroke, Cummins, Duramax, Ram, GM HD gasoline and Mercedes Sprinter engines. Every fact carries a provenance tier (verified, aggregated, contested or data-gap) with its sources and a verification date.

## Features

- 27 engine platforms, 1,200+ vehicle configurations, 800+ part pages, 200+ failure modes
- NHTSA recalls and defect investigations listed per engine
- Free VIN lookup for agents: `https://torqueindex.com/api/vin?vin=<VIN>` (no key, CORS open)
- Markdown twin of every page (`Accept: text/markdown`) and an llms.txt index
