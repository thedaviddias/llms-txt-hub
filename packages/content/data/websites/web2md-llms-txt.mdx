# Web2MD

Free URL to Markdown converter. Paste any public URL and get clean, structured Markdown in seconds — ideal for feeding web content into LLMs, note-taking apps, documentation pipelines, and AI workflows.

## Key Focus Areas

- **URL to Markdown**: Convert any public web page to clean Markdown instantly.
- **Free tier**: 5 conversions per day, no account or signup required.
- **Unlimited access**: License key unlocks unlimited conversions.
- **MCP server**: Use Web2MD as a Model Context Protocol server inside Claude, Cursor, and other MCP clients.
- **REST API**: Simple HTTP API for programmatic URL-to-Markdown conversion.
- **Batch conversion**: Convert multiple URLs at once (Pro).
