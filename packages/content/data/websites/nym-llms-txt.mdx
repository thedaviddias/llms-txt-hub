# Nym

Nym is a personal AI assistant from Metonymous that you text, call, or chat with to finish everyday errands, build private personal apps, and pair with The Scout, a $25 Wi-Fi camera with no required subscription.

## Key Focus Areas

- **Personal AI Assistant**: Handles subscriptions, refunds, meal planning, gift shopping, and scheduled check-ins with user approval before purchases or account changes.
- **The Scout Camera & Agent Ordering**: Includes an agent-readable ordering guide (`/scout/SKILL.md`), live details/order APIs, and a remote MCP server (`https://api.metonymous.ai/v1/scout/agent`).
- **Open Documentation**: Structured product, pricing, integration, and comparison pages for search and answer engines.
