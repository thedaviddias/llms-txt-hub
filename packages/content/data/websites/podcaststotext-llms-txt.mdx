# PodcastsToText

PodcastsToText turns a podcast or video link into an editable transcript with speaker labels and timestamps, exported as TXT, Markdown, SRT, VTT, JSON, DOCX or PDF\.

## Key Focus Areas

- **Podcast to text**: Spotify, Apple Podcasts, YouTube and TikTok links, RSS feeds and audio uploads.
- **AI tools**: show notes, chapters, summaries and translation from a finished transcript.
- **For developers and agents**: a REST API with webhooks and a remote MCP server with OAuth.

## About llms.txt Implementation

The llms.txt file maps the product pages, transcription tools, API and MCP documentation so agents can find the right page, and llms-full.txt carries the full documentation.
