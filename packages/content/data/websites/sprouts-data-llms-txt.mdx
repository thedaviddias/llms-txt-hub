# Sprouts Data

B2B company and people data for AI agents: search, look-alikes, lookups, relationships, research.

## Key Focus Areas

- **Company and people search**: about 45.7 million companies and 204 million people, searched from a plain-English description
- **Look-alike companies**: more companies like 1 to 10 examples you name
- **Record lookups**: full records by domain, LinkedIn URL or record ID; lookups that find nothing are free
- **Relationships and org charts**: how companies or people are connected, and headcount by team
- **Research runs**: multi-step research jobs that state the price first

## About llms.txt Implementation

The Sprouts Data llms.txt links the docs, quickstart, OpenAPI reference, coding-agent guide, MCP setup, pricing and coverage pages, so a model can find how to call the API or connect the MCP server.

## Getting Started

- Hosted MCP server: https://dashboard.sproutsdata.ai/mcp (Streamable HTTP, API key in the X-API-Key header or OAuth 2.1)
- Docs: https://dashboard.sproutsdata.ai/docs
- Test API keys (sk_dsp_test_) search the same data at zero credit cost, and new workspaces get 1,000 free credits.
