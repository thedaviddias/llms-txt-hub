# QRtracer

QRtracer creates dynamic QR codes with editable destinations and scan analytics, alongside static QR tools.

The public documentation describes QR code types, account permissions, the REST API, and the hosted Streamable HTTP MCP server. Account management uses scoped bearer API keys and existing plan limits; public tools support limited anonymous use.

- [MCP connection guide](https://qrtracer.io/qr-code-mcp)
- [API documentation](https://qrtracer.io/docs)
- [OpenAPI description](https://qrtracer.io/openapi.json)
