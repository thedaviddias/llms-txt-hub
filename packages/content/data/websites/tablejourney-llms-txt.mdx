# TableJourney

Food travel guides for 206 cities. Every venue is editorially checked and carries provenance (source URL, date checked, open status) and opening hours; closures are marked rather than deleted. Food festivals are stored as recurrence rules so their next dates resolve automatically. The same data is open to agents through a public, read-only MCP server (https://tablejourney.com/mcp) and a REST API with OpenAPI (https://tablejourney.com/api/v1/docs), no key needed. The guide for agents, including the terms for booking links, is at https://tablejourney.com/agents/.
