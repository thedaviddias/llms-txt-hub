# chucho

chucho helps travelers search vacation rentals, inspect public property details and photos, and reach hosts through direct booking links. Its free public MCP server supports English and Spanish at `https://chucho.ai/chatgpt/mcp` using Streamable HTTP without authentication.

The llms.txt file also describes the host concierge product. Travelers confirm dates, prices, availability, and booking terms on the host website.
