# Free LLM API Hub

Free LLM API Hub is an open dataset of free-tier and trial-credit LLM and AI model APIs. Each field (limits, card or phone required, commercial use, data policy) cites the provider's documentation and carries a check date; values the docs don't state are left null.

## Key Focus Areas

- Free-tier and trial-credit LLM APIs
- No-card, no-phone and commercial-use filters
- No-auth JSON API and CSV (MIT)

## About llms.txt Implementation

The llms.txt summarizes the dataset and links the JSON dataset, its schema, the static JSON API, the guides and the filtered collections. The llms-full.txt expands the full provider list in markdown.
