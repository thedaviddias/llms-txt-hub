# NowPlayingWidget

NowPlayingWidget is a Mac music widget with Compact, Normal and Full desktop sizes, notch and side docks, and a resizable Streaming mode for native capture in OBS or Streamlabs Desktop.

The official llms.txt links public product documentation and Markdown reading copies:

- [Audio sources and compatibility](https://nowplaying.taoftware.com/mac-music-sources/): metadata shared with macOS Now Playing, source-specific controls and a compatibility check.
- [Desktop widget and notch player](https://nowplaying.taoftware.com/notch-music-player-mac/): floating sizes, top-centre mode on flat or notched displays, side docks and appearance.
- [OBS and streaming overlay](https://nowplaying.taoftware.com/obs-now-playing-overlay-mac/): automatic track updates, native window capture, resizing, lyrics and appearance controls.

Source following needs no per-service account connection. The source must publish metadata to macOS Now Playing; OBS still requires window capture and Screen Recording permission. Requires Apple Silicon and macOS 13+.
