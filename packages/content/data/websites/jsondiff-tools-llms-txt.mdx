# jsondiff\.tools

Free JSON tools that run in the browser: semantic diff, formatter, validator, converters and type generators, plus a keyless JSON diff API\.

## What jsondiff.tools is

26 free JSON tools that run in the browser, built around a semantic JSON diff: key order and formatting are ignored, and each difference is reported as a value, type or missing change with its JSON Pointer path. The other tools format, validate, sort and minify JSON, convert to and from YAML, CSV, XML and TOML, generate TypeScript, Go, Python, Java and C# types or a JSON Schema, and test JSONPath and JMESPath queries.

## About the llms.txt

- **Tools**: every tool links to a Markdown version of its page (for example `/json-formatter.md`) with the explanation, examples and FAQ.
- **API**: a free JSON diff HTTP API that needs no key and allows any origin, described in OpenAPI at `/openapi.json`.
- **Privacy**: the web tools process data locally and upload nothing, so agents that cannot run a browser should call the API instead.
