# Sofya

Sofya is a web API for AI agents. One API key gives an agent live web search, any page or document as clean markdown, AI extraction of specific facts from a page, and multi-source research with a cited report. It works over a REST API or a remote MCP server, with pay-as-you-go credits.

## Key Focus Areas

- Web Search API
- Page and Document Fetching to Markdown
- AI Extraction and Cited Research
- MCP Server for AI Agents

## About llms.txt Implementation

Sofya's llms.txt summarizes the four tools, their parameters and credit costs, and links the API docs, OpenAPI spec and MCP setup. The llms-full.txt contains the full API reference in markdown.
