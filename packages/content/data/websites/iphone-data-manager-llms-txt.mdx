# iPhone Data Manager

iPhone Data Manager is a native Apple Silicon (arm64) macOS application that backs up, inspects, compares, and exports iPhone data 100% locally without cloud uploads or user accounts. It features direct external SSD backups, Lean Mode database backups, Data Time Machine backup diffing, tamper-evident SHA-256 WhatsApp PDF transcripts, automated IBAN/lead extraction, and Pro Diagnostics.
