# Bestax

Bestax is a TypeScript React component library for the Bulma v1 CSS framework. Every Bulma element, component, form control and layout is a typed component, with helper props for spacing, colour, typography and flexbox in place of inline styles, and a Theme component for brand colours and dark mode through Bulma's CSS variables.

## Key Focus Areas

- Bulma v1 components for React
- Typed helper props instead of class strings
- Theming and dark mode through CSS variables
- Agent Skills and an MCP server for AI coding assistants
- Migration codemods from older React Bulma libraries

## About llms.txt Implementation

The `llms.txt` file indexes the documentation site by section: getting started, every component's API page, helper props, theming, the Agent Skills and the MCP server. The `llms-full.txt` file carries the full text of those pages, including the props tables and the `tsx` examples, so a model can answer questions about a component without visiting the site. Both are generated from the same source as the docs on each release.
