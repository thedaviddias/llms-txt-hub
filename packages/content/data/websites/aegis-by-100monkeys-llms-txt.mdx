# AEGIS by 100monkeys.ai

AEGIS is a self-hosted orchestrator that runs autonomous agents in isolated, policy-enforced runtimes with durable FSM state. It enforces isolation and policy on every tool call, and each run is a durable state machine. Open source under AGPL-3.0, in beta.

- Install: `curl -fsSL https://get.100monkeys.ai | bash`
- Docs: https://docs.100monkeys.ai (its own llms.txt: https://docs.100monkeys.ai/llms.txt)
- Source: https://github.com/100monkeys-ai/aegis-orchestrator
