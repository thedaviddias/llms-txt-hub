# llms.txt Validator

llms.txt Validator is a free tool that checks a website's llms.txt against the specification, fetches every linked URL to catch broken links, and returns a 0-100 score with actionable fixes.

## Key Focus Areas

- llms.txt Validation
- Link Checking
- Developer Tools

## About llms.txt Implementation

The validator serves its own llms.txt and llms-full.txt, and additionally exposes agent-ready endpoints — a WebMCP tool and an A2A agent card — so both crawlers and AI agents can discover and use it.
