# Comunicate.eu

Romanian platform for publishing press releases, advertorials and SEO articles on a
catalogue of 3,800+ online publications. Prices are printed in the catalogue for each
campaign type, so there is no request for a quote.

The `llms.txt` lists the platform facts, main pages, services, niches, guides, and the
API and MCP endpoints. There is also an OpenAPI 3.1 document, an APIs.json index, an
RFC 9727 API catalogue, and a remote MCP server published in the official MCP registry
as `eu.comunicate/publishing`.
