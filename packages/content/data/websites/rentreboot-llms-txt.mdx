# RentReboot

RentReboot sends apartment alerts and publishes NYC neighborhood asking-rent
percentiles and renter guides. Its llms.txt indexes public resources. The hosted
MCP server is at `https://rentreboot.com/api/mcp`. See the
[hosted MCP setup guide](https://github.com/imiraoui/rentreboot-mcp) for connection
instructions.

Public MCP tools search and read renter guides and retrieve aggregate rent data
without an account. With scoped OAuth consent, connected renters can review their
alerts, manage their saved search, save or track alerted apartments, and view
Housing Lottery application statuses. Authentication and limits are documented at
[rentreboot.com/auth.md](https://rentreboot.com/auth.md).
