# Quantral

Stock sentiment for US and Korean stocks: 0\-100 signal scores from tracked X, Reddit, Substack and Naver accounts plus Congress trades and insider buys, monthly recaps, and rule\-based model portfolios\.

## Key Focus Areas

- **Signal scores**: 0-100 sentiment scores per company, with the posts behind each score. The score measures sentiment, not a price prediction.
- **Congress trades and insider buys**: filings alongside the crowd read for each stock.
- **Strategies**: rule-based model portfolios tracked against the S&P 500, presented as tracked lists, not recommendations.
- **Remote MCP server**: read-only tools at `https://app.quantral.com/api/mcp` for Claude, ChatGPT and other MCP clients.

Our llms.txt and llms-full.txt describe the product, the scoring method, the MCP server and the site's key pages so agents can find the right page.
