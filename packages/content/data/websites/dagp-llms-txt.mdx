# DAGP

Deliberative Agent Governance Protocol: roles, signed parties, pre-elections,
campaign comprehension, citizen votes, monthly agenda credits and milestone budgets.
The starter runs a reproducible synthetic society. Governance currently executes
in the Python reference model; the local G0 blockchain publishes signed documents.

Start at https://dagp.net/start/ or read https://dagp.net/protocol/.
Source: https://github.com/Martines90/dagp (MIT license).
