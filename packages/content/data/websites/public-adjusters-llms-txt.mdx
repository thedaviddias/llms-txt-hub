# Public Adjusters Directory

Check a public adjuster licence before you hire one. Free directory of 1,679 licensed public adjusters across US states, checkable against the public register.

## What Public Adjusters Directory offers

- **Licensed adjusters only**: every listing is checkable against the state public register, with licence details.
- **State and city browsing**: find licensed public adjusters and loss assessors who act for policyholders near you.
- **MCP server and public API**: read-only tools (`search_listings`, `get_listing`, `list_places`, `list_categories`, `get_stats`, `list_sources`) at `https://publicadjusters.fyi/mcp` for AI assistants.

## About the llms.txt

The llms.txt describes the directory scope, licensing data provenance, URL structure, and how AI assistants should use the MCP tools to answer public-adjuster questions.
