# TikTokAPI.io

TikTokAPI.io is a high-speed, developer-first TikTok Data REST API and native Model Context Protocol (MCP) server (`@tiktokapi/mcp-server`) built for AI agents, social listening platforms, influencer marketing tools, and e-commerce ad intelligence.

## Key Focus Areas

- **16 Production REST Endpoints**: 1080p watermark-free video downloads (`hdplay`), keyword video search by region, creator profiles, comments, up to 200 followers per call, and TikTok Creative Center Commercial Ads Library search.
- **Native MCP Server & Claude Skill**: Connect live TikTok data to Claude Desktop, Cursor, and Windsurf via [https://tiktokapi.io/mcp](https://tiktokapi.io/mcp) and [github.com/kaitoInfra/tiktokapi-mcp-server](https://github.com/kaitoInfra/tiktokapi-mcp-server).
- **2026 TikTok API Benchmarks & Engineering Guides**: Side-by-side latency and pricing comparisons ([https://tiktokapi.io/compare](https://tiktokapi.io/compare)), troubleshooting guides ([https://tiktokapi.io/guides](https://tiktokapi.io/guides)), and a free online TikTok ID & `secUid` finder ([https://tiktokapi.io/tools/tiktok-id-finder](https://tiktokapi.io/tools/tiktok-id-finder)).

## About llms.txt Implementation

TikTokAPI.io's `llms.txt` ([https://tiktokapi.io/llms.txt](https://tiktokapi.io/llms.txt)) provides AI coding assistants and autonomous agents with structured documentation across all 16 `/v1/*` endpoints, authentication headers (`x-api-key`), credit pricing (`$1 = 10,000 Credits`), and MCP server tool definitions.
