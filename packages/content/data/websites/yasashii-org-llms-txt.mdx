# yasashii.org

yasashii.org publishes Easy Japanese versions of administrative procedures and disaster-preparedness information for people living in Japan, following the national guidelines on Easy Japanese for supporting foreign residents. Each document shows the date a person last checked the primary sources. It is not a government website; if anything differs from an official government page, the official page is correct.

## Key Focus Areas

- Administrative procedures: resident registration, health insurance, pension, residence status
- Disaster preparedness: earthquakes, typhoons, evacuation shelters, emergency calls
- Furigana and word spacing for learners of Japanese

## About llms.txt Implementation

yasashii.org provides `llms.txt` and `llms-full.txt`, a JSON API, Markdown mirrors of every page, and a read-only MCP server. Content is licensed under CC BY 4.0.
