# GridCore

GridCore makes connected motorsport devices for track days and racing. GridCore One is a 7" touch dashboard, GPS lap timer and data logger in one device; GridCore One Full adds the 1080p50 camera, which is a $350 add-on for the base model. GridCore Nano is a compact windshield lap timer. Both have built-in 4G, so sessions and video sync to the cloud on their own.

## Key Features

- **Lap timing**: GPS lap timer with automatic track detection, live delta and optimal lap
- **Car data**: OBD2 and two CAN FD buses, plus Bluetooth tire sensors
- **Video**: optional 1080p50 camera (included with GridCore One Full) with lap times and car data drawn into the recording
- **Cloud**: built-in 4G, live view for a coach, and a free web app for analysis
- **Open formats**: MoTeC .ld and CSV export
