# NoMac

NoMac gives AI agents a real cloud Mac with Xcode and cloud iPhone Simulators, billed per minute. An agent starts a macOS VM in about a minute, or a Simulator in seconds, over MCP, CLI, REST or SSH. It builds and tests iOS apps, moves files, uploads builds to TestFlight with the account's App Store Connect key, then deletes the machine. Developers on Windows and Linux use it to build iOS apps without owning a Mac.

## Key Focus Areas

- Cloud macOS for AI agents
- Cloud iPhone Simulators for agents
- iOS builds and Simulator tests
- MCP server, CLI and REST API
- TestFlight and App Store Connect

## About llms.txt Implementation

NoMac's llms.txt is the agent manual: how to connect (CLI, hosted MCP with OAuth, REST, SSH), the session loop and its tools, what is installed on the Mac, prices and limits, recovery rules after lost responses, and code signing.
