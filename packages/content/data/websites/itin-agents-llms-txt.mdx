# ITINAgents

Free directory of IRS acceptance agents — 9,838 agents across the US, Canada, UK and India who certify identity documents for ITIN applications.

## What ITINAgents offers

- **9,800+ acceptance agents**: country, region and city pages listing IRS acceptance agents with addresses and contact details.
- **ITIN guides**: what an ITIN is, who needs one, and how the acceptance-agent process works.
- **MCP server and public API**: read-only tools (`search_listings`, `get_listing`, `list_places`, `list_categories`, `get_stats`, `list_sources`) at `https://itinagents.fyi/mcp` for AI assistants.

## About the llms.txt

The llms.txt summarizes the directory scope, the URL structure (country → region → city → agent), and how AI assistants should use the MCP tools to answer ITIN questions.
