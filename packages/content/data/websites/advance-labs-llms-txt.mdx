# Advance Labs

An independent Canadian lab building open-source software for the agent era, and selling the
expertise that built it as answer-engine optimization audits and build sprints.

Its llms.txt is generated from the same source as the site itself, so the human copy and the
machine reading cannot drift apart. The lab also publishes `create-llms-txt`, a command that
writes an llms.txt from a site's own routes, and Human/Machine view, a web component that
shows a site's llms.txt to visitors in place.
