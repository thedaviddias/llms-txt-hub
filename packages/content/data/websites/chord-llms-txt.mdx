# Chord

Chord is a DEX aggregator and on-chain data index. It returns best-route swap quotes and unsigned swap transactions on Ethereum, Base, Arbitrum One, BNB Chain, Avalanche, Monad, Robinhood Chain and Arc, and serves token prices, candles, trades, holders, wallet PnL and liquidity data, including Solana data. Reads need no API key, and a hosted MCP server exposes the same data to AI agents.

## Key Focus Areas

- Best-route DEX swap quotes and unsigned transactions
- On-chain token, trade and wallet data
- REST API and MCP server for AI agents

## About llms.txt Implementation

Chord's llms.txt describes the API (base URL, amounts in smallest units, rate limits) and links the abridged and complete documentation, the OpenAPI 3.1 document, the agent tools manifest and a docs MCP server. The llms-full.txt contains the full developer documentation.
