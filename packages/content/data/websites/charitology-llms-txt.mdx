# Charitology

Open-source public charity registry index (`31` jurisdictions, `3,338,544` official registry records), `48` funding-flow datasets and case studies (including the 5-country European tax-assignment observatory and EU Transparency Register civil-society grants), `65` verified free software/grant/discount programs for charities (`/for-charities/free/`), `42` static CC BY 4.0 JSON endpoints (`/api/v1/index.json`), free MIT-licensed Charity OS (`https://os.charitology.org/`), and a read-only public Streamable HTTP MCP server (`https://os.charitology.org/mcp`).
