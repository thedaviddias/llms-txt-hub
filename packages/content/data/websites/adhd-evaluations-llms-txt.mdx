# ADHDEvaluations

Find an ADHD evaluation provider near you. Free directory of 9,846 ADHD evaluation providers across 54 US states, districts and territories, from the CMS NPI Registry.

## What ADHDEvaluations offers

- **9,800+ providers**: state and city pages listing ADHD evaluation providers with addresses, sourced from the CMS NPI Registry.
- **Evaluation guides**: what an ADHD evaluation involves, what it costs, and how to choose a provider.
- **MCP server and public API**: read-only tools (`search_listings`, `get_listing`, `list_places`, `list_categories`, `get_stats`, `list_sources`) at `https://adhdevaluations.fyi/mcp` for AI assistants.

## About the llms.txt

The llms.txt describes the directory scope, the NPI data provenance, URL structure, and how AI assistants should use the MCP tools to answer ADHD-evaluation questions.
