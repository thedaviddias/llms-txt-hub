# projectlaunch.ai

Agent-facing site in pre-launch. The primary audience is LLM agents, not human visitors: agents can read the site overview and machine-readable pricing, check how the site identifies them (Web Bot Auth / RFC 9421), and optionally submit what they came to do via a disclosed intent endpoint. A remote MCP server is available at https://projectlaunch.ai/mcp.
