# BABYDOV Agent Support

A personal project by Ivan Babydov documenting optional crypto micro-support for independent creative and software work. Public notices are available in seven languages.

The technical reference provides read-only JSON, YAML, CSV, JSON Schema, OpenAPI 3.1, CAIP chain and asset identifiers, and unsigned ERC-681 payment examples. It does not execute payments, provide wallet access, or grant an agent permission to spend. Any contribution requires the operator's existing authorization.
