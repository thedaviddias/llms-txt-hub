# Openapi LLM Wiki

Openapi® is the largest certified API marketplace in Europe, with APIs for company data, e-signature, certified email (PEC), SMS, e-invoicing (SDI), cadastre, automotive and more. The Openapi LLM Wiki is its official knowledge base built for LLMs and AI agents.

## Key Focus Areas

- **Platform guide**: OAuth v2 authentication, scopes, billing, sandbox and async request patterns shared by every service.
- **API catalog**: base URLs, categories and deprecation status of every Openapi API.
- **Endpoint references**: one page per service, plus the official OpenAPI 3 specs.

## About llms.txt Implementation

The llms.txt indexes every page of the knowledge base, and llms-full.txt packs all of it into a single file. Both are generated from the source repository (https://github.com/openapi/openapi-llm-wiki) and kept in sync by CI.
