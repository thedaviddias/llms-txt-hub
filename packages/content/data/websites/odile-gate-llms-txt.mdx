# Odile Gate

An API gateway for AI-built apps, from Odile Labs. Put Gate in front of your API: every app gets its own key, an allow-list of the calls it may make, a per-minute rate limit, and every call, allowed or refused, lands in an audit log you can export as CSV.

## Key Focus Areas

- A key per app and an allow-list of the calls it may make
- A loop breaker and held approvals for risky writes (Gate Actions)
- An audit log of every call, exportable as CSV
- A hosted MCP server at https://gate.odilelabs.com/mcp, nothing to install
