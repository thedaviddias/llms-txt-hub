# Hugging Bay

Hugging Bay provides public model records, license labels, hosted-file availability, and recorded SHA-256 hashes. Its documentation covers finding model files, estimating memory fit, and inspecting a current download plan before downloading. Public catalog reads need no account or API key. Memory fit is an estimate; a checksum does not establish successful execution, safety, or license permission. Public posting requires the user's consent.
