# Dish Directory

Free directory of restaurants across the United States. Browse restaurants by state, county, city, and cuisine category, with addresses, phone numbers, and hours.

## What Dish Directory offers

- **Restaurant listings nationwide**: state, county, and city pages with restaurant names, addresses, phone numbers, and cuisine categories.
- **Category browsing**: find restaurants by cuisine type within each city.
- **MCP server and public API**: read-only tools (`search_listings`, `get_listing`, `list_places`, `list_categories`, `get_stats`, `list_sources`) at `https://dishdirectory.com/mcp` for AI assistants.

## About the llms.txt

The llms.txt describes the directory scope, the URL structure (state → county → city → restaurant), and how AI assistants should use the MCP tools to answer restaurant questions.
