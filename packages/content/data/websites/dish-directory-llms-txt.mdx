# Dish Directory

Free directory of restaurants across the United States and Canada. Browse restaurants and their dishes, prices and hours by country, region and city.

## What Dish Directory offers

- **Restaurant listings**: country, region and city pages with restaurant names, dishes, prices and hours.
- **Category browsing**: find restaurants by cuisine type within each city.
- **MCP server and public API**: read-only tools (`search_listings`, `get_listing`, `list_places`, `list_categories`, `get_stats`, `list_sources`) at `https://dishdirectory.com/mcp` for AI assistants.

## About the llms.txt

The llms.txt describes the directory scope, the URL structure (country → region → city → restaurant), and how AI assistants should use the MCP tools to answer restaurant questions.
