# okdata

okdata is a pay-per-call API and hosted MCP server for public social and content data. One key reads TikTok, YouTube, Instagram, X, Reddit, the Meta and Google ad libraries, and Chinese platforms such as Douyin, Xiaohongshu (RedNote), Weibo, Bilibili and WeChat, without platform accounts or cookies.

## Key Focus Areas

- Social media data API: posts, comments, profiles, transcripts and trending lists
- MCP server for AI agents in Claude, Cursor and other clients
- Chinese social platforms with English field names
- A fixed price for every endpoint, listed in the catalog

## About llms.txt Implementation

okdata's llms.txt lists every endpoint with its price and links the Markdown version of each page; every public page on the site has a .md twin. The llms-full.txt carries the full catalog with parameters and returned fields. A Chinese llms.txt is at /zh/llms.txt, and /agents.md gives coding agents the setup steps.
