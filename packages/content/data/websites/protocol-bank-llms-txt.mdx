# Protocol Bank

Non-custodial AI trading agent on Hyperliquid. The agent wallet holds trading-only permissions, so the AI can trade but can never withdraw; the maximum possible loss is the funded budget, shown on screen at all times. Includes a free paper-trading mode on real market data, a public anonymized live track record, and an MCP server for controlling the agent from any MCP host.
