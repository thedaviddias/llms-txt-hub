# Sealed Rose

Sealed Rose is an AI media forensics platform for detecting synthetic video deepfakes, cloned audio, and AI\-generated images using spectral and metadata analysis\.

## Key Focus Areas

- **Multimodal Deepfake Forensics**: Detects synthetic video generation artifacts, frame-level temporal inconsistencies, and facial reenactment manipulations.
- **Acoustic and Image Provenance**: Analyzes voice clone spectral phase anomalies, frequency-domain image artifacts, C2PA Content Credentials, and EXIF container metadata.
- **Privacy-Preserving Verification**: Supports client-side cryptographic hashing and media authenticity verification workflows for journalists and security teams.
