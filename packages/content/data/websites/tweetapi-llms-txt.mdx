# TweetAPI

Third\-party Twitter data API for tweets, profiles, followers, lists, communities and Spaces, with a hosted MCP server\.

TweetAPI's llms.txt covers what the Twitter data API returns, how pricing and billing work, and where to find the OpenAPI spec, the Python and Node.js SDKs, and the hosted MCP server. The llms-full.txt file is the complete endpoint reference, with the required fields, an example request and the cost of every call.
