# Leaf

Free, open-source ebook reader for Mac that opens EPUB, MOBI, AZW3, PDF, FB2 and CBZ files like documents: double-click to read, close the window to quit. No library, no account, no copies. Highlights, notes and bookmarks export as Markdown or Kindle's My Clippings format; vertical Japanese text is supported; eight interface languages.

## Key Focus Areas

- Ebook reading on macOS
- EPUB, MOBI and AZW3 without a library
- Highlights, notes and export
