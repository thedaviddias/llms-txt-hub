# Sorsa API

Read\-only REST API for public X \(Twitter\) profiles, posts, search and follower data, with an MCP server for AI clients\.

## Sorsa API

Sorsa API provides read-only access to public X (Twitter) data for developers and compatible AI clients.

- [Product website](https://api.sorsa.io/)
- [Developer documentation](https://docs.sorsa.io/)
- [OpenAPI specification](https://api.sorsa.io/v3/swagger.json)
- [MCP server](https://github.com/Sorsa-io/sorsa-mcp)

Sorsa API is independent of X Corp.
