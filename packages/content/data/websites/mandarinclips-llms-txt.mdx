# MandarinClips

MandarinClips is an immersion-focused Chinese language learning platform built from authentic Chinese movies and television series. It provides English-speaking learners and CSL educators with a sentence-level dialogue concordancer spanning 182,404 live video clips and 412,323 verified dialogue lines, so any phrase, vocabulary item or grammar pattern can be studied in real cinematic context.

## Key Focus Areas

- Sentence-level search across authentic cinema dialogue (Simplified Chinese, tone-marked Pinyin and English)
- HSK proficiency tags (Levels 1-6) with grammar sentence blueprints
- 10-dimensional pragmatic context: scene categories, native English subtext analysis, communicative functions and register formality
- Non-linear semantic graph of similar phrasings, contrasting retorts and conversational alternatives
- Official MCP server (`com.mandarinclips/mcp`) for AI agents, with a hosted endpoint and an npm stdio package

## About llms.txt Implementation

MandarinClips' llms.txt opens with the corpus overview and verified scale (182,404 live dialogue clips, 412,323 spoken dialogue lines), then documents core capabilities including multi-modal tracks (Simplified Chinese characters, tone-marked Pinyin and English translations), flexible full-text search across characters and untoned Pinyin, HSK proficiency tags, 10-dimensional pragmatic context, a non-linear semantic graph and instant audio shadowing. It lists all core content hubs under the canonical `/en/` route (expressions, grammar, pragmatic scenes, shows directory and unified corpus search), defines the clip URL slug convention, notes the permanent 301 redirects from legacy language prefixes, names the four target audiences, and closes with the platform contact and fair-use statement.
