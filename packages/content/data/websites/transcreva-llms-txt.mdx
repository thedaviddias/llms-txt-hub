# Transcreva

Transcreva converts Brazilian Portuguese audio and video recordings (MP3, M4A, WAV, WhatsApp OGG/Opus, MP4, MOV, WebM) into structured text with interactive timestamps, speaker diarization (`Locutor 1`, `Locutor 2`), and exports to TXT, DOCX, SRT, and VTT.

## Key Focus Areas

- **Brazilian Portuguese Speech-to-Text**: Calibrated for PT-BR accents, technical vocabulary, and WhatsApp voice notes.
- **Speaker Diarization & Subtitle Generation**: Automatic speaker separation for interviews and legal hearings, plus millisecond-accurate SRT/VTT subtitle export.
- **Developer API & MCP Server**: Includes a remote Model Context Protocol (MCP) server (`https://transcreva.net/mcp`) and CLI (`transcreva-mcp`).

## About llms.txt Implementation

Transcreva provides structured `llms.txt` and `llms-full.txt` documentation covering all PT-BR transcription workflows, pricing tiers, REST API endpoints, and MCP server tools.
