# Hydromancer

Hydromancer is data infrastructure for Hyperliquid. It provides a REST API, WebSocket streams and L2/L4 order book feeds for teams building on Hyperliquid, plus Reservoir, a free archive of Hyperliquid historical data stored as Parquet files on AWS S3.

## Key Focus Areas

- Hyperliquid REST API (positions, fills, orders, liquidations, vaults)
- Real-time WebSocket streams and L2/L4 order books
- Free historical market data (Reservoir)
- HIP-3 and HIP-4 market data
