# AssemblyAI

AssemblyAI builds Voice AI models and the APIs developers use to run them: speech-to-text for pre-recorded, streaming and synchronous audio, the Dictation API, Speech Understanding (summarization, sentiment analysis, speaker identification, translation and more), Guardrails (PII redaction, content moderation, profanity filtering), text-to-speech, and LLM Gateway for applying large language models to transcripts.

## Key Focus Areas

- Speech-to-Text
- Streaming Transcription
- Dictation
- Speech Understanding
- Text-to-Speech
- LLM Gateway

## About llms.txt Implementation

AssemblyAI's llms.txt indexes the full documentation and API reference, with every docs page linked as Markdown. It also lists section files, each holding one docs section's full Markdown in a file small enough for an agent to read in one fetch, and an integration prompt for AI coding agents. The llms-full.txt holds all docs pages and API specs in a single file.
