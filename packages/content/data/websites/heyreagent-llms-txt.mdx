# HeyReagent

HeyReagent connects your own LinkedIn account to the AI app you already use. A hosted MCP server and API let Claude, ChatGPT, Cursor or n8n read your inbox, send messages and connection invitations, and search people, and an agent plan answers your inbox in your voice for you to approve. It is an independent service, not affiliated with LinkedIn.

## Key Focus Areas

- Hosted LinkedIn MCP Server
- LinkedIn Inbox and Messaging
- Connection Invitations and People Search
- AI Agent for LinkedIn Follow-up

## About llms.txt Implementation

HeyReagent's llms.txt has four sections, Docs, Actions, Guides and Optional, with a link to every docs page, every action and every guide. The llms-full.txt carries the full text of the docs in one file.
