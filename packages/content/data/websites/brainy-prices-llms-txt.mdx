# Brainy Prices

UAE cost of living data: school fees (KHDA), registered rents (DLD), fuel, utilities, telecom plans and relocation costs, with source and date on every answer.

## API and MCP

Read-only REST API v2 and remote Streamable HTTP MCP v2, with no authentication.

- [Developer documentation](https://prices.brainy.ae/developers.html)
- MCP endpoint: `https://prices.brainy.ae/mcp/v2`

## Source terms

KHDA non-commercial; DLD Dubai Open Data Licence. Service licence: per-source terms, see /developers.html.
