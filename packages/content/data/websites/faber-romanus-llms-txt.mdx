# Faber Romanus

Documentation for Faber Romanus, an experimental programming language designed to be written by language models and read by people.

## About llms.txt Implementation

The llms.txt file points coding agents to the Faber writing guide, the install route and the agent skill catalog. llms-full.txt is the keyword catalog, a lookup list rather than a tutorial.
