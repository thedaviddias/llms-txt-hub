# Bucketlist.nl

Bucketlist.nl helps people discover experiences by destination or theme and save a personal bucket list with a free account. The main interface and editorial content are Dutch.

Its public llms.txt links to the experience catalogue, editorial policy, printable Netherlands checklist and documented daily JSON API. The API is keyless and supports cross-origin reads; it is a daily inspiration feed, not a general-purpose travel database.

Browsing and saving ideas are free. Some experience pages contain clearly labelled affiliate links to external booking providers.
