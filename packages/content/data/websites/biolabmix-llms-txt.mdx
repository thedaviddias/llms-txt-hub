# Biolabmix

Производитель реагентов, наборов и компонентов для молекулярной биологии, генетики, диагностики и биотехнологии. Каталог включает ПЦР-смеси для реального времени и классической ПЦР, наборы для выделения ДНК и РНК, ферменты, компоненты и наборы для синтеза мРНК in vitro, олигонуклеотиды, тест-системы для выявления патогенов (SPF-виварии, птицеводство, рыбоводство, сельское хозяйство), и оборудование для ПЦР-лабораторий.
