# BlockVectra

BlockVectra documents EVM JSON-RPC access, indexed on-chain data and a hosted MCP server for developers and AI agents.

## Task guides

- [Robinhood Chain RPC and chain ID](https://docs.blockvectra.com/en/guides/robinhood-chain/): Read network identity before using the selected RPC endpoint.
- [Robinhood testnet starter](https://docs.blockvectra.com/en/guides/robinhood-testnet-starter/): Start with public testnet reads and follow the guide for authenticated WebSocket access.
- [Robinhood testnet faucet](https://docs.blockvectra.com/en/guides/robinhood-testnet-faucet/): Find test ETH funding options for testnet development.

## Documentation access

The English llms.txt index links to task guides and API references. The llms-full.txt resource contains the full English documentation. Public RPC methods and limits follow the live chain catalog; indexed Data API and account operations require an API key.
