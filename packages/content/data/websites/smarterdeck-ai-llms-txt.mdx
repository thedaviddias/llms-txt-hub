# SmarterDeck AI

Generate executive PowerPoint decks, interactive KPI dashboards, and wikis from confidential PDFs and Excel files with Zero\-Retention security\.

## Overview

SmarterDeck AI is an enterprise AI workspace designed for executive consultants, financial analysts, and corporate leaders. It ingests complex financial PDFs, raw spreadsheets, and unstructured documents to synthesize them into executive-level PowerPoint presentations (.pptx), interactive KPI dashboards, and neural wikis with Zero Data Retention.

## Core Architectural Pillars

- **Native OpenXML DrawingML Vector Engine**: Unlike wrapper tools that export flat images or screenshots, SmarterDeck compiles layouts into 100% editable Microsoft PowerPoint vector objects and shapes (`<p:sp>`).
- **In-Memory Zero Data Retention (ZDR)**: Ephemeral processing runs entirely in volatile RAM on Google Cloud Run. Documents are streamed via signed time-limited tokens and never stored on disk or used for AI training.
- **5-in-1 Executive Suite**: Every generation delivers an editable `.pptx` deck, an interactive HTML KPI Dashboard, a web presentation, a high-density infographic, and an executive PDF.
- **Model Context Protocol (MCP)**: Native integration for Claude Desktop, Cursor, and autonomous AI agents.

## Supported Data Sources

- Financial Statements (10-K, 10-Q, P\&L, Balance Sheets)
- Pitch Decks & Investment Teasers (CIMs)
- Unstructured PDFs, Excel workbooks, and CSV files
- Direct prompt synthesis in Blueprint mode
