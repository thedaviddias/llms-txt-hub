# Tale

Tale is an open-source project workspace where teams assign tasks to people and configured AI agents, keep context in persistent sandbox workspaces, and review delivered files. It supports self-hosted and managed deployment, with model credentials configured separately.

## About llms.txt Implementation

Tale's documentation index links to Markdown pages covering project tasks, agent runtimes, automations, API access, and deployment. A separate [website index](https://tale.dev/llms.txt) covers product information and comparisons.
