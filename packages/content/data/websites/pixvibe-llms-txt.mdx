# PixVibe

PixVibe is a private image toolkit for you and your AI agents. Remove backgrounds, upscale, compress to an exact size, convert HEIC, WebP, AVIF, PNG and JPG images to PNG, JPG, WebP or AVIF, crop and resize. The free tools run in the browser, so images are processed on the device that opens the page.

## Key Focus Areas

- Background removal, upscaling, compression, format conversion, cropping and resizing
- Agent-ready links: every free tool can be driven from one URL with an image URL and settings
- On-device processing for the free tools

## About llms.txt Implementation

PixVibe's `llms.txt` explains how an AI agent can run any free tool from a single link, wait for the result and download it. A human-readable version is at https://pixvibe.ai/agents.
