# Kvartiry-Phuket

Kvartiry-Phuket is a Russian-language reference on buying, renting and owning condominiums and apartments in Phuket, Thailand. It publishes editorial guides (purchase routes, freehold vs leasehold, taxes, visas, due diligence), district overviews, dated asking-price aggregates from observed public listings, the official Thai Treasury condominium assessment rates, and travel data for the island: live MET Norway weather, monthly climate normals, 25 beaches, webcams and the sea state today.

## Key Focus Areas

- Phuket real estate guides for Russian-speaking buyers
- Dated asking-price aggregates by district and bedroom count (listing prices, not transaction prices)
- Official condominium assessment rates from the Thai Treasury Department
- Weather, climate by month, beaches, webcams and sea state

## About llms.txt Implementation

The llms.txt lists the key sections and guides with one-line summaries, plus a block of short dated answers to frequent questions (median asking prices, price per square metre, dry season, sea temperature), each linked to its source page. The llms-full.txt carries the full Markdown text of the published guides. The same source-linked data is also available through a JSON API (/api/v1/) and a remote MCP server (/mcp), both free and without a key.
