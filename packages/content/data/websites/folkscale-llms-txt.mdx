# Folkscale

Folkscale is a country-calibrated synthetic consumer research studio. Agents and research teams can generate national panels, run Semantic Similarity Rating (SSR) studies, and get Likert distributions, verbatims and a PDF brief. The live Streamable HTTP MCP endpoint is https://mcp.folkscale.com/mcp. Full machine-readable docs are in /llms-full.txt.
