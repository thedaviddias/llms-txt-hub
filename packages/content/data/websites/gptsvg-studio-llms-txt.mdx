# GPTSVG Studio

GPTSVG Studio generates clean, editable XML `<svg>` vector paths from text prompts or raster images for brand logos, 24x24 monoline UI icons, and transparent die-cut stickers, alongside a free client-side Image-to-SVG vectorizer.

## Key Focus Areas

- Native text-to-SVG and image-to-SVG vector path generation across eight design styles
- Free zero-login browser Image-to-SVG converter on `/image-to-svg` plus 1024px–4096px transparent PNG export
- One-time non-expiring credit packs with automatic credit refunds on failed generations
