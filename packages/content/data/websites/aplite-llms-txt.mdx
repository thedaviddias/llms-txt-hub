# Aplite

Hosted AI agents in a markdown workspace: they read and write your notes, run routines on a schedule and publish pages\. Built on OpenClaw, free plan\.

## What Aplite is

Aplite runs AI agents for you on a server: each workspace is a standard OpenClaw runtime in its own container, set up from the browser in about a minute. The agents work inside a markdown workspace — they read and write your notes, run routines on a schedule, deliver results to Telegram or email, and build pages you can publish at a link. Edits to your notes wait in an approval queue until you accept them.

- **Models:** any model from the catalog via OpenRouter, prepaid credits (1 credit = 1¢), no API key needed
- **Plans:** Free, Pro $20/mo, Power $50/mo
- **Hosting:** Germany (EU), operated by PIKsolution OÜ, Estonia
