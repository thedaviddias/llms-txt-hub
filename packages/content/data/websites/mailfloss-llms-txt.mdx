# mailfloss

mailfloss is an email verification service. It connects to 40+ email platforms, including Mailchimp, Klaviyo and HubSpot, and automatically verifies addresses, fixes typos and removes bounces. Developers and AI agents use the same verification through a REST API with an OpenAPI 3.0 spec.

## Key Focus Areas

- Email verification and list cleaning
- Typo correction and bounce removal
- Native email platform integrations
- Email verification REST API for developers and AI agents
