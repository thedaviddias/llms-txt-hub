# Foundplay

Foundplay is a free discovery platform for browser games. Most of the games are originals by independent creators, many made with AI tools. Each listing links to the creator's own site, where the game plays in a browser tab with no download. New games go live together every day at 6 AM and 6 PM Pacific.

## Key Focus Areas

- Browser game discovery: lists, genres, collections, most played and trending
- Phone-friendly and multiplayer filters
- New game drops twice a day
- Free listings for game creators

## About llms.txt Implementation

Foundplay's llms.txt is built from the live listings: current facts (games listed, plays so far), answer pages such as games to play with friends online, the week's most played games, collections, genres, and the games API and MCP server for assistants. llms-full.txt adds every listed game, one line each, most played first.
