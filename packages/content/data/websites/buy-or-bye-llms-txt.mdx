# Buy or Bye

Buy or Bye is a community where people post what they are about to buy (or watch, play, eat, or visit), with the price and their reason, and other people vote Buy it or Bye and comment with owner experience, cheaper deals and alternatives. It is available in English, Vietnamese, Simplified Chinese and Traditional Chinese.

## Key Focus Areas

- Purchase debates — post an item, price and reason; the crowd votes and comments
- Boards — buy, watch, play, eat and go, plus a general yes/no board
- Four languages — vi, en, zh, zh-tw
- Agent access — MCP server, A2A agent and a public OpenAPI 3.1 REST API

## About llms.txt Implementation

The llms.txt lists the main feeds and boards, the agent endpoints (Streamable HTTP MCP server at /mcp, A2A, OpenAPI, Agent Skill) and the usage policy. llms-full.txt adds the tool schemas. Every page can also be fetched as Markdown with `Accept: text/markdown`.
