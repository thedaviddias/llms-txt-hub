# Condux

Source\-available error monitoring with an AI fix engine that opens draft pull requests your team reviews and merges\. Managed cloud or self\-host\.

## What the file covers

- **Developers:** the docs, the Sentry migration guide, the control plane's OpenAPI document, the Postman collection, the MCP server card, and the SDK and platform source on GitHub.
- **Integrations:** GitHub, Slack, Sentry SDK compatibility, OpenTelemetry logs and the MCP server.
- **Use cases:** error monitoring, AI bug fixing and CVE remediation.
- **Plans:** Free, Team, Business and Enterprise with their limits, above the first section.
- **Self hosting and licensing, who it is for, and company and legal pages.**
- **Optional:** comparisons with Sentry, BugSnag, Rollbar, Honeybadger, Raygun, Snyk, Dependabot, GlitchTip, Highlight and Better Stack.

## How it is kept current

The file is generated when the site builds, from each page's own title and description, so it changes when a page does. The build fails if a page lacks a description or a sitemap page is missing from it.
