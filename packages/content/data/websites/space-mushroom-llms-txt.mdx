# Space Mushroom

Space Mushroom is a free, open materials database covering metals, polymers, ceramics, composites and space materials (vacuum, radiation, atomic oxygen, thermal cycling). Every value is shown with its unit, test conditions, method and the source, including the place in it. Data is licensed CC BY 4.0.

## Key Focus Areas

- Materials Property Data
- Sourced Values with Test Conditions
- Space Environment Materials
- Read-only MCP Server for AI Agents

## About llms.txt Implementation

Space Mushroom's llms.txt explains how to find a material, read a profile and cite it, links the JSON and CSV data files for each profile, and lists the collections and the remote MCP server at https://spacemushroom.com/mcp.
