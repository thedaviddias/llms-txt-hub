# Supero

Supero is a backend platform for apps written by AI coding assistants. You describe the app to
Claude, ChatGPT, Cursor or another MCP client; the assistant calls Supero's remote MCP server
(https://mcp.supero.dev/mcp, OAuth sign-in) to define schemas, publish the app and deploy it.
Supero provides the parts the generated code should not have to reinvent: tenant isolation,
role-based access, workflows, integrations such as Stripe, email and SSO, admin and customer
screens, and hosting.

## Key Focus Areas

- Remote MCP server for building and deploying apps
- Multi-tenant data isolation
- Role-based access control
- Workflows and approvals
- Payments, email, SMS and SSO integrations
- Python SDK (`pip install supero`)
- Hosted deployment
