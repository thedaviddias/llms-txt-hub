# Vidbyte

Vidbyte builds tools for AI agents. vidbyte-sdk is a free, MIT-licensed Python library for building agents that call your own functions as tools, with middleware such as a per-run dollar cap estimated from tokens, evaluations and tracing. vidbyte-cli is a terminal app that starts hosted research runs with every source cited and summarized, runs small teams of local Codex coding agents on one change, and turns a goal into a ranked list of next actions. Vidbyte agent skills are SKILL.md files that let Claude Code, Codex and other coding agents hand one job to a Vidbyte agent through vidbyte-cli; some are marked coming soon. The SDK is free and the CLI is free to install. Hosted research and local agent launches draw from a prepaid balance, and the SDK's default-mode model calls carry a 2% Vidbyte fee on top of the model cost. Next-action suggestions cost 1 cent each from the balance, charged before the run starts, and their model use stays on the user's own signed-in Codex or Claude Code account (full pricing: vidbyte.pro/docs/pricing).
