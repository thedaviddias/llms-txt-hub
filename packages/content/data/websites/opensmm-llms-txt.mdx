# OpenSMM Protocol

OpenSMM is an MIT-licensed, provider-neutral protocol for ordering SMM services
(followers, views, reactions, retention) from AI agents. The reference gateway
exposes the same domain objects over REST `/v0` and MCP, with protocol-level
idempotency and a catalog assembled from independent provider nodes. Providers
are onboarded without code; a provider that sets a `payoutAddress` is paid
directly in USDC on Base via x402, while the gateway routes and measures the
orders and never holds funds.
