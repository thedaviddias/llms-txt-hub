# Ownkube

Ownkube is a cloud for personal software. One prompt to production: tell your coding agent to deploy a repo, and it ships the web app to a live HTTPS URL, along with any workers, scheduled jobs, managed Postgres databases, or Valkey caches it needs.

## Key Focus Areas

- Deploy from any coding agent through the hosted MCP server (Claude Code, Cursor, Codex, GitHub Copilot, Windsurf, Zed)
- Web apps, workers, scheduled jobs, managed Postgres and Valkey caches
- Every app gets its own HTTPS hostname
- Logs, metrics and health checks for every deployment
- One-click open-source apps from the Marketplace
- Prepaid wallet from a $5 top-up, billed per minute, and unused credit never expires
- The okctl CLI for deploys, logs and connection details from the terminal
- The same app can move to your own AWS account with no rewrite

## About llms.txt Implementation

Ownkube publishes both `llms.txt` (concise index of pages, docs and agent runbooks) and `llms-full.txt` (full content of the marketing site and blog), generated at build time and served from the same origin as the public site. Markdown versions of key pages (`/index.md`, `/pricing.md`, `/prompt.md`) are linked from the index so agents can read them directly.
