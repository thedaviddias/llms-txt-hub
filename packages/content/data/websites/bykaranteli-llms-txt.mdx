# ByKaranteli

ByKaranteli is a free crypto derivatives data terminal. It covers funding rates and cross-exchange funding arbitrage, open interest, multi-exchange liquidation maps, Deribit options flow, spot ETF flows, CFTC COT positioning, Coinbase premium and VPIN order-flow toxicity. Every live page is public with no account, programs read the JSON API under `/api/public` with a free account key, daily CSV and JSON datasets are free for personal and research use with attribution (a CC0 archive to 2026-09-10 is on GitHub), and the same data is exposed to agents through the `bykaranteli-mcp` MCP server (45+ read-only tools, MIT licensed, also reachable as a hosted Streamable HTTP endpoint at `https://mcp.bykaranteli.com` that needs no key). Pages ship in four languages: English is canonical and every indexable page has Simplified Chinese, Russian and Korean twins under `/zh`, `/ru` and `/ko`.
