# ByKaranteli

ByKaranteli is a free crypto derivatives data terminal. It covers funding rates and cross-exchange funding arbitrage, open interest, multi-exchange liquidation maps, Deribit options flow, spot ETF flows, CFTC COT positioning, Coinbase premium and VPIN order-flow toxicity. Every live page is public with no account, the JSON API under `/api/v1/public` needs no key, historical datasets are published under CC0, and the same data is exposed to agents through the `bykaranteli-mcp` MCP server (33 read-only tools, MIT licensed, also reachable as a hosted Streamable HTTP endpoint at `https://mcp.bykaranteli.com`). Pages are bilingual: English is canonical and every indexable page has a Simplified Chinese twin under `/zh`.
