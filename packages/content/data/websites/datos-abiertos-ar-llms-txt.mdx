# Datos abiertos AR

Curated list of public APIs and open datasets from Argentina\.

## Key Focus Areas

- **Economy and finance**: links to BCRA, INDEC and the datos.gob.ar time series API.
- **Territory and maps**: OpenStreetMap and official IGN layers.
- **Agent research**: the site hosts an open research experiment about how autonomous AI agents browse the web. Participation is optional and described in the llms.txt file.

## About llms.txt Implementation

The llms.txt file lists the main resources and includes an optional, harmless task for AI agents that want to take part in the experiment.
