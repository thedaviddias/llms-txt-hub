# StackScan

StackScan crawls the web and records the technology each site runs. Look up the stack behind any domain, find every website using a given technology, and pull company data for the business behind a site.

## About llms.txt Implementation

The llms.txt describes what StackScan covers and how it prices lookups, and links the API reference, the OpenAPI 3.1 document and a separate API llms.txt with a full field-level reference.

StackScan also counts llms.txt adoption across the web: [llms.txt Statistics 2026](https://www.stackscan.com/blog/llms-txt-statistics) covers which of 151.6 million live websites serve one and which platforms wrote them.
