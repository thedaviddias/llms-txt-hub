# Hypra

A markup language whose compiler turns one file into accessible HTML, Markdown for AI agents and typed tools.

## Key Focus Areas

- **Markdown for agents**: every page also compiles to Markdown, served from the same URL to clients that ask for `text/markdown`, with a list of the actions an agent can take on the page.
- **Checked at compile time**: missing alt text, unlabeled fields and skipped headings stop the build, with a fix for each.
- **WebMCP tools**: forms and buttons become tool definitions with JSON Schemas.

## About llms.txt Implementation

The llms.txt lists the language reference, the guides and a page for each compiler rule, each linked as Markdown. llms-full.txt has all of the documentation in one file.
