# LinkIntel

LinkIntel is an MCP server that gives Claude or any MCP-compatible assistant evidence for its next social post. It never publishes and never searches X on its own.

## Key Focus Areas

- **Owned performance**: reads your recent original X posts and their metrics daily once you connect X.
- **Ranking signals**: tracks X's open-source ranking weights.
- **Reference sets**: stores public X posts you choose as references for a topic, then returns everything as a cited content brief over MCP.

## About llms.txt Implementation

The llms.txt file explains what LinkIntel does and does not do, when an agent should reach for it, how to connect over OAuth 2.1, the tool call order, and pricing, so an assistant can set it up without a browser.
