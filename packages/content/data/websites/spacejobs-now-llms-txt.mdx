# SpaceJobs.Now

SpaceJobs.Now lists the open jobs and internships at launch providers, satellite and spacecraft makers, space agencies, defense primes and their suppliers, read every day from each employer's own careers site with the pay each posting states, and sorted by kind of work, state and country.

## Key Focus Areas

- Space industry jobs and internships
- Posted pay by kind of work
- Open jobs API and MCP server for agents

## About llms.txt Implementation

SpaceJobs.Now provides an `llms.txt` file with the board's current size, its pages by kind of work, place and term, and its free JSON API and MCP server.
