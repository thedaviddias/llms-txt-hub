# Open Agent Guide

Open Agent Guide is a free AI-native ecosystem directory for humans and agents. Search the catalog to compare products by capabilities, pricing, compliance, and available APIs, SDKs, and MCP servers.

The llms.txt file links to the catalog, API documentation, and agent connection instructions. Agents can read the catalog through the HTTP API or connect to the Open Agent Guide MCP server.
