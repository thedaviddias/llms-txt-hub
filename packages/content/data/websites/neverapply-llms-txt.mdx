# NeverApply

NeverApply is an AI job-search agent. It matches job seekers to roles, tailors resumes, answers screening questions, prepares candidates for interviews, and applies to jobs once the user approves each one, or without waiting for approval when the user has given one assistant a separate send grant.

## Key Focus Areas

- Hosted MCP server at https://neverapply.co/mcp (Streamable HTTP, OAuth 2.1 with PKCE)
- MCP setup documentation for Claude, Cursor, Cline and other clients
- Job matching, resume tailoring and application tracking
