# Talo Pay

Talo Pay is an Argentine payments platform that automates bank-transfer collections for e-commerce. Each order receives a unique CVU and alias; Talo detects the transfer, confirms the order and settles funds immediately.

## Key Features

- **Unique CVU/alias per order**: Automatic reconciliation of bank transfers
- **Instant confirmation**: Orders are confirmed as soon as payment arrives
- **E-commerce integrations**: Plugins and API for online stores
- **MCP server**: Agent-ready tooling for payments workflows
