# Sóley

Sóley is a direct booking network for travel in Iceland, built for AI assistants and agents. One remote MCP server connects an assistant to licensed Icelandic tour, activity and accommodation operators. The assistant searches by place, type and price, reads each operator's details and cancellation policy, checks availability, and gets quotes in ISK and the traveller's own currency. The traveller confirms with a one-time code sent to their own email and pays the operator through one consolidated payment link. Each operator is the merchant of record; Sóley never holds traveller funds.

## Key Focus Areas

- Booking licensed Icelandic tours, activities and stays from AI assistants
- Live Iceland data: road conditions, weather, aurora forecast, earthquakes, safety alerts, public buses and flights
- A remote MCP server at https://api.soley.travel/mcp with OAuth 2.1, plus a read-only public REST API
