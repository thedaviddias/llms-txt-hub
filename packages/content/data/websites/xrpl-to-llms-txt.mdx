# XRPL.to

XRPL.to is an explorer and data API for the XRP Ledger: token prices and charts, holders, trades on the ledger's built-in DEX and AMM pools, NFTs and accounts.

## Key Focus Areas

- XRP Ledger token prices, OHLC candles and holders
- DEX and AMM trades and pools
- NFTs, collections and accounts
- REST and WebSocket API, plus an MCP server for AI agents

## About llms.txt Implementation

XRPL.to's llms.txt tells AI agents and coding assistants to use the API instead of scraping pages. It lists the base URL, the docs, the OpenAPI spec and the MCP endpoint, gives a map of endpoints to start from, and states the attribution rule.
