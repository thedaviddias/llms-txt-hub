# Tipline

Tipline is an unofficial fan guide to Grand Theft Auto VI. Each page is written in its own words and links to the public sources behind every fact. It is not affiliated with Rockstar Games or Take-Two Interactive.

## Key Focus Areas

- Characters, places, vehicles, weapons and activities, one page per topic
- Release time for each country, with a live countdown
- Missions, story-mode cheats and collectibles as they are confirmed after launch
- A question box that answers only from the guide's sourced pages

## About llms.txt Implementation

The llms.txt lists every page with a one-line summary and points AI assistants to a read-only REST API (search, entries, release times) and a remote MCP server, so answers can cite the page and its sources.
