# pic2svg

pic2svg traces raster artwork into editable SVG paths. SVG downloads are free without signup; PDF, EPS, AI and DXF exports require a paid plan or trial. The hosted converter uploads images to its own tracing server.

The documentation explains the tracing pipeline, format limits, public HTTP API and preparation of SVG files for printing or cutting. It also links to a free browser-based SVG markup checker and measured tracing examples.
