# AIFont

The font library for image AI\. Copy a prompt into ChatGPT, Gemini or Grok and get your word in that lettering style\. Tested on 5 models in 7 languages\.

## Key Focus Areas

- Copy-ready lettering prompts for AI image models (graffiti, script, gothic, 3D, holiday styles and more)
- Side-by-side, unretouched results from five image models for every prompt
- Seven languages, including right-to-left Arabic
- Open data on how accurately image models spell text

## About llms.txt Implementation

AIFont's llms.txt describes what an AI font is, lists the site's languages and main sections, and links a selection of AI font pages with a one-line description of each look, so an assistant can point a user to a matching prompt.
