# APPLORE

APPLORE is an app icon inspiration library and a set of AI tools for app makers. It collects 18,000+ real icons from the App Store and Google Play, sorts them by color, style and category, and archives every past version of each icon.

## Key Focus Areas

- App icon inspiration library with archived icon versions
- AI app icon generator that uses real icons as style references
- Icon export to every iOS, Android and web size
- AI logo animation with Lottie export
- App Store screenshot generator
