# Tanod

Tanod is a set of pay-per-call tools for AI agents and developers, over HTTP and MCP, with a free daily allowance and no account.

## Key Focus Areas

- PDF, image and document tools: merge, split, compress, OCR, form fill, tables, PDF to Word, Office to PDF, any document to Markdown
- Web, DNS and email checks, web search, page to Markdown and screenshots
- Solidity contract scans, address risk checks and MCP/skill package scans before install
- Paid per call in USDC over x402, or free within the daily allowance
- 150+ free browser tools in 12 languages, listed in a second file at https://tanod.dev/tools/llms.txt

## About llms.txt Implementation

https://tanod.dev/llms.txt describes every API family, its endpoints, prices and the MCP server address; https://tanod.dev/tools/llms.txt lists each free tool with a one-line description.
