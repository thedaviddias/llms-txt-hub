# Animara

Animara makes animated device icons and ready made dashboards for Home Assistant. 300 devices with 792 real states move with the state of the device (a fan turns, a washer drum spins), inside the cards people already use, in light and dark mode, on phones, tablets and wall panels. Install is one link pasted into Home Assistant. A free open source sampler of 12 icons (MIT) is on GitHub.

## Key Focus Areas

- Home Assistant dashboards and wall tablets
- Animated SVG device icons
- Smart home user interface

## About llms.txt Implementation

Animara's llms.txt lists every product with its price, the install and help pages, and short facts about how the icons and dashboards work, so assistants can answer questions about animated icons and wall tablet dashboards for Home Assistant.
