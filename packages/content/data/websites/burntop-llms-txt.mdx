# burntop

burntop is the site for fullstack-ai-template, an open-source full-stack template for apps that AI coding agents build. It gives you FastAPI, React 19 (TanStack Start), Tailwind 4, shadcn/ui and PostgreSQL, with session auth, Google OAuth, a reference CRUD feature and 203 end-to-end tests. Mocks and untested routes fail the build, so the agent can't fake a green check.

## Key Focus Areas

- Full-stack project template (FastAPI, React 19, PostgreSQL)
- Guardrails for AI coding agents (Claude Code, Cursor, Codex)
- End-to-end testing with real Postgres and Playwright
- AGENTS.md files and agent skills

## About llms.txt Implementation

burntop's llms.txt tells an agent how to start a project from the template (one prompt or the `gh repo create --template` command), lists the stack, what is included, the guards that fail the build, and links to the source repo and demo apps.
