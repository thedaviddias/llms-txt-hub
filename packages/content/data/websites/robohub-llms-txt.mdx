# RoboHub

RoboHub is an independent, vendor-neutral directory of commercial robots in 7 languages, with specs, side-by-side comparisons and price provenance. Only maker-published USD prices count as verified. A public MCP server (Streamable HTTP, no API key) exposes search, robot detail and comparison tools. It is not affiliated with robohub.org.
