# AION 2 Pets

Independent AION 2 pet atlas, recorded soul maps, Insight calculators and a local checklist with JSON backup\. Free fan resource\.

## What this resource covers

AION 2 Pets is a free independent fan guide for planning pet collection. The atlas has 206 records across five genera; 157 have recorded coordinates across three regions. Map pins are reference locations, not guaranteed drops or measured drop rates.

## Tools and data handling

- Search pet records and inspect acquisition sources.
- Compare common-pet EXP rewards and estimate analysis costs.
- Keep a manual checklist in the current browser. Export JSON and merge a validated backup for manual transfers.
- No game-account connection, automatic cloud sync, or gameplay automation.
