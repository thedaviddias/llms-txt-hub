# PienoFurbo

Italian fuel prices from official MIMIT open data \(IODL 2\.0\): 23,000\+ stations, daily updates, public REST API and no\-auth JSON endpoints\.

## Key Focus Areas

- **Open government data**: daily import of the MIMIT "Osservaprezzi carburanti" dataset (IODL 2.0 licence), covering 23,000+ Italian fuel stations
- **API documentation**: public REST API documented at /api/docs, plus no-auth JSON endpoints for stations and regions
- **Data processing**: per-station price history, regional averages, and filtering of misreported prices
- **Machine-readable exports**: GPX, KML, CSV and GeoJSON

## About llms.txt implementation

/llms.txt lists the main sections and public endpoints; /llms-full.txt adds a condensed corpus with live national price statistics, regenerated daily.
