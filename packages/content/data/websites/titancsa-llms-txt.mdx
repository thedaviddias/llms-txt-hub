# TitanCSA

TitanCSA publishes Windows developer SDKs for remapping compatible physical input devices, creating virtual USB devices, using applications built for the original Interception C API, and routing audio between applications.

## Documentation

- English and French first-run instructions for six Windows products.
- Signed demo downloads and an integration manifest with exact package versions, hashes, and expected test results.
- Installation, activation, and SDK guides with links to the published test evidence.
