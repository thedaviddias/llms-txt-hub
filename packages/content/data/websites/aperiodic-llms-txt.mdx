# Aperiodic

Aperiodic provides point-in-time crypto market microstructure, liquidity and order-flow metrics (220 metrics in 19 datasets), plus the raw trades, quotes and derivatives data behind them, for perpetuals on venues including Binance, OKX and Hyperliquid. Data is delivered as parquet through a CLI, a REST API and a Python SDK.

## Key Focus Areas

- Crypto Market Microstructure Data
- Liquidity and Order-Flow Metrics
- Raw Trades and Quotes
- Quant Research and Backtesting

## About llms.txt Implementation

Aperiodic's llms.txt tells an agent how to fetch the no-key preview slice, make a keyed call, and find every dataset, with a link to the markdown version of each catalog page and the raw-data page. The llms-full.txt is the long-form reference with the full dataset and pricing details.
