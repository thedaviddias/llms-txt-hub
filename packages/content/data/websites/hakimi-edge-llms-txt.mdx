# Hakimi Edge

Hakimi Edge is an open-source, zero-dependency Cloudflare Workers suite built for developers and autonomous AI agents. It includes DomainCheck (SPF/DMARC/DNSSEC and HTTP security header grader with live SVG badges), LLMsReady (an `llms.txt` and AI-readiness GEO auditor and auto-generator), and AgentKit (a pay-per-request x402 v2 edge API and Streamable HTTP MCP server).

## Key Focus Areas

- AI-Readiness & `llms.txt` Auditing and Generation (LLMsReady)
- DNS, Email Deliverability (SPF/DMARC/CAA/DNSSEC) & HTTP Security Header Grading (DomainCheck)
- Pay-Per-Request x402 v2 Edge APIs & Streamable HTTP MCP Server (AgentKit)
- Zero-Dependency, MIT-Licensed Cloudflare Workers Self-Hosting

## About llms.txt Implementation

Hakimi Edge publishes both `/llms.txt` and `/llms-full.txt` on its documentation hub along with machine-readable `/.well-known/x402`, `/mcp.json`, and `/openapi.json` manifests across all hosted edge tools so AI agents can discover, inspect, and invoke every utility directly.
