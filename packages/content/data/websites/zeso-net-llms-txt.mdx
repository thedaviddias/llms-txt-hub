# Zeso

Zeso is an AI site builder and web host — site, domain, and hosting on one
platform. A one-page site is free forever.

Every site it hosts can publish its own `llms.txt` and `llms-full.txt`, a
server-stitched schema.org `@graph`, and a native MCP endpoint, so an AI agent
can read the site rather than guess at it.
