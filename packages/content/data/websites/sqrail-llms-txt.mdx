# sqrail

sqrail is an MIT-licensed single-binary C++20 CLI built around embedded DuckDB v2.0.0 that exposes a narrow, deterministic SQL execution boundary over local CSV, TSV, JSON, JSONL, and Parquet files for coding agents and shell pipelines.

## Key Focus Areas

- **Explicit File Capability**: SQL queries can read only local paths explicitly bound with `-t name=path`; external access and extension loading are disabled and locked.
- **Read-Only and Non-Destructive**: Accepts a single `SELECT`, `VALUES`, or `WITH` query per invocation and commits `-o` output files atomically without overwriting existing files.
- **Enforced Resource Budgets**: Enforces `--memory`, `--threads`, `--timeout`, `--max-rows`, `--max-output-bytes`, `--max-input-files`, `--max-sql-bytes`, and isolated `--spill` limits.
- **195-Word CLI Contract and Agent Skill**: Emits pure streaming JSONL on stdout while keeping stderr empty on normal success (emitting one versioned JSON object on stderr only on failure or when `--stats` is requested), paired with an installable `SKILL.md` for coding agents.
