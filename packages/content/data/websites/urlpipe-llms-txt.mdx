# URLpipe

URLpipe is a per\-URL web data API and hosted MCP server: Markdown, screenshots, metadata, console errors and Lighthouse audits for any page, rendered in real Chrome\.

## Key Focus Areas

- **Pages as model input**: clean Markdown of what a reader sees, measured against the rendered page, for LLM and RAG pipelines.
- **Agents**: a hosted MCP server, so an agent can read single\-page apps that return an empty shell to a plain fetch.
- **One URL, several answers**: screenshots, Open Graph and JSON\-LD metadata, console errors and Lighthouse from the same page visit.

## About llms.txt Implementation

URLpipe's llms.txt and llms\-full.txt are generated from the same registries as its docs and site, so every product page, docs page and guide is listed and stays in step with what the site says.
