# Plainrouter

Plainrouter connects Meta advertising and first-party conversion tracking to developer workflows through APIs, SDKs and a hosted MCP server. Its public documentation covers setup, authentication, conversion diagnostics and changes governed by workspace policy.

The production MCP endpoint uses OAuth or a workspace key. A separate synthetic sandbox lets developers check their client connection without accessing an advertising account. Meta is supported today; educational Google Ads and TikTok guides do not imply supported integrations.
