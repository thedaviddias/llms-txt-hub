# AnswerRail

AnswerRail is a developer tool, CLI library, and software development framework that generates /llms\.txt manifests, validates Schema\.org markup, and serves clean Markdown to AI crawlers via an edge API and Next\.js SDK\.

## Key Focus Areas

- **CLI and Schema Auditor**: Open-source command-line utility and web scanner for validating robots.txt directives, JSON-LD Schema.org markup, and HTML token weight.
- **Automated llms.txt Generation**: Compiles and hosts structured llms.txt and llms-full.txt documentation indexes across WordPress, Shopify, Webflow, static HTML, and Next.js.
- **Edge Markdown Content Negotiation**: Layer-7 reverse proxy and Next.js SDK middleware serving deterministic Markdown to AI search crawlers via RFC 9110 content negotiation.

## About llms.txt Implementation

The AnswerRail llms.txt and llms-full.txt manifests index our technical documentation, CLI reference, API endpoints, and engineering guides for AI agents and developer tools.
