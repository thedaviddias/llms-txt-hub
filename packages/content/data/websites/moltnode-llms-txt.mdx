# MoltNode by Chord

MoltNode is a multi-chain RPC gateway with one URL per chain and no API key: JSON-RPC 2.0 over HTTP POST for 31 blockchains, including Ethereum, Base, Arbitrum, BNB Chain, Avalanche, Monad, Solana and Sui. Its hosted MCP server lets AI agents read chains and get swap quotes with unsigned transactions through Chord.

## Key Focus Areas

- Keyless JSON-RPC endpoints for 31 blockchains
- Hosted MCP server for AI agents
- Swap quotes and unsigned transactions through Chord

## About llms.txt Implementation

MoltNode's llms.txt explains how to connect the MCP server, lists the endpoint for every chain, and gives example JSON-RPC requests and the swap flow.
