# PlushSource

An independent directory of custom plush makers\. Browse the full factory list by MOQ, country, certifications and design files; no field is estimated\.

## plushsource-mcp (Model Context Protocol server)

PlushSource also ships an open-source MCP server so AI agents can search the PlushSource directory of custom plush manufacturers directly.

- npm package: plushsource-mcp - run with `npx -y plushsource-mcp`
- Transport: stdio; no API key required
- 5 tools plus an `rfq_draft` prompt for drafting an inquiry to a manufacturer
- Repository: `https://github.com/quickman924/plushsource-mcp`

The site publishes llms.txt at `https://plushsource.com/llms.txt` for AI assistants.
