# BannerGen

AI-powered social media banner generator: generate professional banners for Twitter/X, LinkedIn, Instagram, YouTube, Facebook, and GitHub OG images.

## Key Focus Areas

- Free browser banner maker (no sign-up, no API key)
- Web app with bring-your-own-key image generation
- CLI tool with 6 platform templates (Twitter/X, LinkedIn, Instagram, YouTube, Facebook, GitHub OG) and 5 visual styles (Modern, Minimal, Bold, Elegant, Fun)
- Brand name + tagline overlay and batch processing from text files
- Pay-what-you-want from $1 on Gumroad; MIT licensed source
