# Handles API

Handles API is a REST API for public social media data from X (Twitter), Instagram, TikTok, YouTube, Telegram, Bluesky, Twitch, Kick and LinkedIn. One key, one credit system and one JSON envelope cover 113 endpoints: profiles, posts, followers, growth history, search and cross-platform identity lookups. It also runs a remote MCP server so agents can call the same data as tools.

## Key Focus Areas

- Social media profile and post data
- Follower and growth analytics
- Cross-platform identity lookup
- MCP server for AI agents

## About llms.txt Implementation

The llms.txt lists the quickstart, authentication, credit model, error codes and a link to a markdown page for every endpoint in the API reference. The llms-full.txt contains the full markdown of the docs and reference, so an agent can read the whole API surface in one request.
