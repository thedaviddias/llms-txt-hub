# Treved

**Small apps. Big attention to detail.**

Treved is an independent software studio focused on creating small, useful, and thoughtfully designed digital products.

The goal is simple: build software that is easy to use, fast, privacy-conscious, and genuinely useful — without unnecessary complexity.

## About

Treved develops and maintains a growing collection of software products across different categories and use cases.

Each project is built with the same principles in mind:

- **Simplicity** — straightforward products without unnecessary features or complexity.
- **Performance** — fast, responsive, and lightweight experiences.
- **Privacy** — collecting as little user data as reasonably possible.
- **Quality** — attention to detail throughout development and maintenance.
- **Usefulness** — solving real problems and providing genuine value.
