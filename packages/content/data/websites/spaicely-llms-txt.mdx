# Spaicely

Static website hosting in the EU on your own domain\. Your own AI assistant (Claude, ChatGPT, Gemini, Claude Code) registers the domain, uploads and publishes the site and sets up DNS, forms, a shop and mail through the Spaicely MCP server; a dashboard and a CLI do the same without AI\.

## About llms.txt Implementation

llms.txt describes the service, prices and the public domain search API, and points AI assistants to the MCP connector, the developer docs and the skills for building and running a site\. llms-full.txt adds the complete reference of MCP tools and HTTP endpoints\.
