# esyURL

esyURL is a link shortener built for AI agents. There's no dashboard: an agent creates short links and QR codes, changes where they point, and reads visit analytics through an MCP server or a REST API with an OpenAPI schema. Redirect rules send each visitor to the right place by device, OS, language, country, referrer, query or time, so one QR code can open the App Store on iPhones and Google Play on Android. Each account can bring its own custom domain, with HTTPS handled. Agents without a key sign themselves up by following auth.md, and pay for a new custom domain with x402 (5 USDC on Base, once per domain). Created in 2007, rebuilt for agents in 2026.
