# ailiste

ailiste is a free map of new builds in Cyprus: 3,613 buildings across Limassol, Paphos, Larnaca, Nicosia and Famagusta, 672 of them photographed on site with the date. Each building has the construction stage seen there, its developer and every listing for it in one place, over the asking price per square metre of each district. In English, Greek, Russian, Ukrainian, Hebrew and Chinese.

## Key Focus Areas

- New-build homes in Cyprus
- Construction stages and photos taken on site
- Asking prices per m² by district
- A free MCP server for AI agents

## About llms.txt Implementation

ailiste's llms.txt says what the site is, how to connect an AI assistant to its free MCP server (https://mcp.ailiste.app), which tools the server offers and how to answer with them, and links the pages an agent should read: the map, the buildings, the developers, what the property portals get wrong, and each city's prices by district.
