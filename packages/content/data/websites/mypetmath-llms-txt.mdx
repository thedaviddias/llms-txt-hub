# MyPetMath

Free dog and cat calculators for US pet owners. Every tool shows its formula, a step-by-step worked example and its veterinary sources (Merck Veterinary Manual, AAHA, WSAVA, AAFP, university vet schools, and peer-reviewed papers). Estimates for healthy pets, not veterinary advice.

## About llms.txt Implementation

MyPetMath publishes an `llms.txt` file at https://www.mypetmath.com/llms.txt with an overview of the calculators, guides and sources, so LLM tools can cite the specific page for each tool.
