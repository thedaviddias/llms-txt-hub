# SendHQ

SendHQ is a workspace-scoped email API for product email. It supports sending from verified domains, inbound email, hosted templates, delivery events and suppressions, with a web dashboard, a CLI and an MCP server for AI agents.

## Key Focus Areas

- Transactional email API
- Inbound email
- Hosted templates
- Deliverability and suppressions
- MCP server for AI agents
