# Every Signal

Every Signal is a marketing intelligence API that audits AI\-written marketing against real teardowns and measured conversion rates\.

## Key Focus Areas

- **Audit AI-written marketing**: copy, landing pages, emails, ads, funnels and SEO are scored against teardowns of real companies, with findings that cite the record behind each claim, fixes and a rewrite.
- **For agents**: remote MCP server (API key or OAuth), REST API with OpenAPI, a Claude skill and a one-line `npx` install.
- **Sourced teardowns**: a public library of company teardowns where every figure is tagged verified, estimate, inferred or rumour.
