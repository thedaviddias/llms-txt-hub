# Massvai

Massvai is an AI full-stack app builder that turns a plain-language prompt into a working Next.js app you can preview, edit and deploy.

## Key Focus Areas

- **Prompt to app**: describe an app in plain language and get a production-ready Next.js project with live preview.
- **Full-stack tooling**: AI coding agent, Supabase integration, GitHub sync and one-click Vercel deployment.
- **Docs and guides**: product overview, pricing, FAQ and a blog with practical AI app-building guides.
