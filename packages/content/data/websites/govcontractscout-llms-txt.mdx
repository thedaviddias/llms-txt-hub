# GovContractScout

US state and local government contracts data. Search active contracts, get details, NAICS lookup, AI match scoring. Also an MCP server (npm govcontractscout-mcp).

## About llms.txt Implementation

GovContractScout provides an `llms.txt` file with AI-readable information about its documentation, product, or website content.
