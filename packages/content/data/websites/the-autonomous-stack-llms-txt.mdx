# The Autonomous Stack

Catalog of runnable BYO-LLM agent packs for developers: Python agent code, a systemd service, offline tests and LLM-readable specs\. Most packs cost $3, payable by card or over x402\.

## Key Focus Areas

- **Agent packs**: each pack is a downloadable agent (task queue, retries, systemd unit, offline tests) with README, SPEC, PROMPTS and CHECKLIST files that a coding agent can read.
- **BYO-LLM**: the core runs without an API key and calls the model the user configures.
- **Agent purchasing**: an autonomous agent can buy a pack over x402 (HTTP 402, USDC on Base).

## About llms.txt Implementation

The llms.txt describes the x402 purchase flow step by step and lists every pack with its name, price, file list, purpose and metadata endpoint. A JSON-LD catalog is also served at /api/v1/discover.
