# MetaPilot

MetaPilot writes schema\.org structured data, Open Graph and llms\.txt for every page and keeps it current, served through Cloudflare with no code changes\.

## What MetaPilot does

MetaPilot writes schema.org structured data, Open Graph tags and llms.txt for every page of a website, from what each page actually says, and keeps them current as the pages change. It serves them at the edge through Cloudflare, so nothing in the site's own code has to change.

## How it uses llms.txt

- **Its own files**: metapilot.io publishes both llms.txt and llms-full.txt, plus a Markdown version of every page.
- **For the sites it manages**: MetaPilot generates and serves llms.txt and llms-full.txt for each connected site, so AI assistants get a clean map of the site without anyone editing it by hand.
- **Kept current**: when a page changes, its entry is written again.

## Approval or autopilot

Every change can wait for approval as a diff against the live page, or run on autopilot.
