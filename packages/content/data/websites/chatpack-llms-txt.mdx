# Chatpack

Chatpack adds chat to applications using the developer's own database and authentication. It includes direct and group conversations, messages, permissions, read state, and real-time delivery, with a typed browser client and React UI blocks.

The documentation's llms.txt index links to setup instructions, storage adapter guides, framework integrations, and the REST API reference.
