# MemoryCareHomes

Free directory of memory care homes in the UK and US, checkable against the public register. Browse 17,000+ licensed facilities by country, region and city, with licence numbers and capacity.

## What MemoryCareHomes offers

- **Licensed facilities only**: every listing is checkable against the public register, with its licence number and licensed capacity.
- **Location browsing**: country, region and city pages so families can compare licensed memory care options near them.
- **MCP server and public API**: read-only tools (`search_listings`, `get_listing`, `list_places`, `list_categories`, `get_stats`, `list_sources`) at `https://memorycarehomes.fyi/mcp` for AI assistants.

## About the llms.txt

The llms.txt describes the directory scope, licensing data provenance, URL structure, and how AI assistants should use the MCP tools to answer questions about licensed memory care.
