# MemoryCareHomes.fyi

Free US directory of licensed memory care homes. Search state-licensed dementia and Alzheimer care facilities by state, county, and city, with license numbers and capacity.

## What MemoryCareHomes.fyi offers

- **Licensed facilities only**: every listing carries its state license number and licensed capacity, sourced from state licensing databases.
- **Location browsing**: state, county, and city pages so families can compare licensed memory care options near them.
- **MCP server and public API**: read-only tools (`search_listings`, `get_listing`, `list_places`, `list_categories`, `get_stats`, `list_sources`) at `https://memorycarehomes.fyi/mcp` for AI assistants.

## About the llms.txt

The llms.txt describes the directory scope, licensing data provenance, URL structure, and how AI assistants should use the MCP tools to answer questions about licensed memory care.
