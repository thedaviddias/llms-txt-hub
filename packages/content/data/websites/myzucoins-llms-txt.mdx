# MyZucoins

Tools and services for Zucoin's Splitchain layer 1 network, with an MCP server that connects AI agents to guides, developer docs and news\.

MyZucoins provides tools, services and developer resources for Zucoin's Splitchain layer 1 network. Its open Model Context Protocol (MCP) server connects AI coding assistants and agents to Splitchain guides, wallet help, developer tutorials and ecosystem news.

## MCP server

- URL: `https://myzucoins.org/mcp` (Streamable HTTP, no authentication)
- Docs: [myzucoins.org/mcp-api-docs](https://myzucoins.org/mcp-api-docs)

MyZucoins needs no account, subscription or API key. The MCP server is read-only: it cannot access wallets, sign or send transfers, or give live prices.
