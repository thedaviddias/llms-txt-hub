# Cork & Curve

Wine travel guides for 37 European wine regions in 8 countries. Every vineyard, tasting room, wine bar and cellar is editorially checked and carries provenance (source URL, date checked, open status) and opening hours. Wine festivals come with resolved dates. The same data is open to agents through a public, read-only MCP server (https://corkandcurve.com/mcp) and a REST API with OpenAPI (https://corkandcurve.com/api/v1/docs), no key needed. Guide for agents: https://corkandcurve.com/agents/.
