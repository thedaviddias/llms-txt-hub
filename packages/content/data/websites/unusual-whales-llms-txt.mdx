# Unusual Whales

Options flow, dark pool, congressional trades and Greek exposure data for traders, with a REST API, an official MCP server and an agent skill\.

## Key Features

- **REST API**: 200+ endpoints at `https://api.unusualwhales.com` covering options flow, dark pool, congressional trades, Greek exposure, volatility, futures and prediction markets. Docs: `https://api.unusualwhales.com/docs`
- **Official MCP server**: hosted at `https://api.unusualwhales.com/api/mcp` (Bearer API key) or local via `npx -y @unusualwhales/mcp`. Source: `https://github.com/unusual-whales/unusual-whales-official-mcp`
- **Agent skill**: `https://unusualwhales.com/skill.md`
- **Second llms.txt for the API reference**: `https://api.unusualwhales.com/llms.txt`
