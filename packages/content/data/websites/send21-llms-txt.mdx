# send21

send21 creates pay links, payment requests and payment drafts for BTC (on-chain and Lightning), USDC, USDT, EURC, SOL and ETH, and watches the chain until the payment confirms. The payer signs and sends from their own wallet; send21 never holds private keys or funds.

## Key Features

- **Pay links in any currency**: price in crypto or 161 fiat currencies with a locked rate
- **Built for AI agents**: REST API with scoped keys and an MCP server at https://send21.io/mcp
- **Signed webhooks**: draft.confirmed and other events, signed with a timestamped HMAC (X-Send21-Signature-V2) against replays
- **Non-custodial**: no key can move funds
