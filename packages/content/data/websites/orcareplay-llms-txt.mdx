# OrcaReplay

OrcaReplay records a coding-agent run below the harness and replays it offline from the recorded bytes, with no model called. One npm package named orcareplay puts one command named orca on the PATH; the agent itself runs unmodified while a base-URL proxy captures the request and response bytes exchanged with the model, alongside shell, MCP and filesystem capture layers. A recorded run can be re-executed without calling the model again and without spending tokens, or forked at a chosen step onto a different model so that the model is the only variable in a comparison. Replay is not a sandbox: recorded shell and MCP tool calls still execute, and a tool that opens its own connection can still reach the network. Apache-2.0 for the code, CC BY 4.0 for the trace-format spec, Node 20+.
