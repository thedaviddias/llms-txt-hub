# whichapi

whichapi is a free search engine for AI agents. An agent (or a developer) describes a task in plain words, such as "convert scanned PDF to text" or "live crypto prices", and gets back the services that can do it: paid pay-per-call endpoints (x402, MPP), free MCP servers and agent skills, with the price per call and how many distinct buyers each paid service had in the last 30 days.

## Key Focus Areas

- API and tool discovery for AI agents
- Pay-per-call endpoints (x402, MPP) ranked by real buyers
- Remote MCP server, A2A agent and HTTP API

## About llms.txt Implementation

whichapi's llms.txt lists every entry point an agent can use: the free HTTP search, the paid x402 search, the remote MCP server and its tool, the A2A agent card, the OpenAPI description and the per-need service pages.
