# AI for Database

AI for Database connects to live operational databases such as Postgres, MySQL and SQL Server. People ask questions in plain English, build dashboards and set up workflows that alert them when the data changes. Its public REST API and remote MCP connector let applications and AI agents do the same.

## Key Focus Areas

- Natural-language database queries
- Dashboards
- Data alerts and workflows
- REST API for AI agents
- MCP connector for Claude and ChatGPT
