# FeraTerra

Headless L3 central limit order book exchange for perpetuals, spot, and basis spreads with MCP and OpenAPI 3\.1 endpoints for autonomous AI agents\.

## Key Focus Areas

- **Headless L3 CLOB Venue**: Deterministic fixed-point C++23 matching engine on Base for perpetual futures, spot markets, multi-leg baskets, and perp-spot basis spreads with self-custodial EIP-191 wallet authentication.
- **Stateless Pre-Trade Simulation**: Read-only `POST /order/preview` dry-run endpoint returning fill price, slippage, fees, and post-trade Eigen-SPAN margin impact with zero state mutation.
- **Native Agent Transports**: Streamable HTTP and `stdio` Model Context Protocol (MCP) 24-tool server, OpenAPI 3.1.0 schema (`/openapi.json`), WebSocket feeds, Python SDK (`feraterra-sdk`), and 64-byte binary wire protocols.

## About llms.txt Implementation

FeraTerra's `llms.txt` manifest documents live node posture, exact integer tick and lot scaling, EIP-191 and HMAC-SHA256 authentication flows, non-custodial Base settlement, stateless order preview, OpenAPI 3.1 discovery, and MCP tool integration so AI agents can inspect markets and construct valid requests directly.
