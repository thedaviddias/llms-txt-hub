# aikstockdata

aikstockdata publishes data on companies listed on KOSPI, KOSDAQ and KONEX: settled closing prices from the Financial Services Commission's public data feed, DART regulatory filings with the minute each one was received, earnings from periodic filings, and a daily price history for each stock. The files are machine-readable JSON with no sign-up and no API key.

## Key Focus Areas

- Korean listed-company closing prices (previous trading day, not live quotes)
- DART filings with receipt timestamps
- Post-filing price paths by filing type
- A remote MCP server for AI assistants

## About llms.txt Implementation

The llms.txt describes the data files, the remote MCP endpoint (https://mcp.aikstockdata.com/mcp) and the usage terms: non-commercial use with attribution; commercial redistribution is not permitted. The llms-full.txt describes the published data files and the rules for reading the responses. The site gives no recommendations of any kind.
