# Stellary

Stellary is an AI-native project piloting platform. It unifies boards, documents, cockpit-style delivery, and governed AI agents, with a hosted Model Context Protocol server at `https://api.stellary.co/mcp`.

## Key Focus Areas

- Project piloting
- Remote MCP
- AI agents

## About llms.txt Implementation

Stellary publishes an `llms.txt` file with AI-readable product, documentation, comparison, and MCP setup context.
