# Thally

> Thally is an MIT-licensed documentation engine built on Next.js and MDX. Every page is published as HTML, Markdown and JSON, alongside llms.txt, llms-full.txt and a read-only MCP endpoint.

## Key Focus Areas

- Documentation sites
- Agent-readable docs
- MCP server for documentation

## About llms.txt Implementation

Thally's llms.txt indexes its documentation pages with short summaries and lists agent-facing resources: per-page Markdown and JSON via content negotiation, a search API, an OpenAPI spec and an MCP endpoint. The llms-full.txt contains the full Markdown content of the documentation.
