# Pailiku

Pailiku (牌力库) is a bilingual (Chinese/English) Texas Hold'em educational reference: hand rankings and rules, pot odds, outs, ICM and range equity calculators, a hand equity table whose heads-up preflop equities are computed by enumerating every board (not Monte Carlo sampling), a poker glossary and an open odds dataset (CC BY 4.0).

## About llms.txt Implementation

Pailiku provides an English `llms.txt` that lists its core references, deterministic calculators, open data files and glossary, and states the site's editorial limits.
