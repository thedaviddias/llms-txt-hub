# Kiwi News

Kiwi News is an open-source, Hacker News-style link aggregator for crypto and Ethereum. Anyone can post with an Ethereum wallet or a passkey. Submissions, upvotes and comments are signed messages synced between nodes peer-to-peer.

## Key Focus Areas

- Community-curated crypto and Ethereum links
- Public JSON API, RSS feeds and an MCP server
- Peer-to-peer replicated, open-source (GPL-3.0)

## About llms.txt Implementation

Kiwi News's llms.txt points agents to plain-text versions of story pages and weekly top-story pages, the RSS feeds, the public JSON API (no auth, CORS open) and how to cite stories.
