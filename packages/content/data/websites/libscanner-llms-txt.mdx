# libscanner

libscanner makes two libraries for industrial DataMatrix marking: dmr reads GS1 DataMatrix codes from conveyor camera frames, and dmgen generates DataMatrix ECC 200 symbols as PNG or JPEG.

## Key Focus Areas

- **dmr (reader)**: reads codes at around 2 pixels per module, every candidate verified by Reed-Solomon error correction; GS1 and Chestny ZNAK (Russian product marking) codes.
- **dmgen (generator)**: all 24 square sizes, six encodation schemes, GS1 and Chestny ZNAK validation, self-check by reading every symbol back.
- **Interfaces**: C++20 API, flat C ABI, Python packages on PyPI (libscanner-dmr, libscanner-dmgen) and a command-line tool for Windows and Linux (x86-64, ARM64, ARMv7).
