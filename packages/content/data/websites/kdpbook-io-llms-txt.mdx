# kdpbook.io

AI book studio for Amazon KDP: describe a book in a chat and get the print PDF, full-wrap cover, Kindle eBook and listing, ready to upload.

## About llms.txt Implementation

kdpbook.io provides both `llms.txt` and `llms-full.txt`. Both files are generated from the product code, so the book types, formats, pricing and KDP print rules they describe stay in step with the live site.
