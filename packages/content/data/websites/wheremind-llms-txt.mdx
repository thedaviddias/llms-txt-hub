# Wheremind

Wheremind is a hosted MCP server that gives AI agents and assistants live places search, geocoding, nearby search and directions, so they stop guessing addresses and routes. It works in Claude, ChatGPT, Cursor and Claude Code over Streamable HTTP at https://wheremind.ai/mcp, with sign-in from the app and no API keys to manage.

## Key Focus Areas

- Places search and place details for agents
- Forward and reverse geocoding
- Nearby search around a point
- Driving, walking and transit directions

## About llms.txt Implementation

Wheremind's llms.txt is the agent contract: it gives the MCP endpoint, the tools and when to use them, how to connect from each supported client, and links to the FAQ and maps MCP overview pages.
