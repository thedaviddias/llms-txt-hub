# KokybiskaSvetaine\.lt

One\-person web studio in Lithuania: custom WordPress websites, WooCommerce stores, Laravel systems, technical SEO and AI search \(GEO\) optimisation\.

KokybiskaSvetaine.lt is the one-person web studio of Justas Arbatauskis, a web designer and developer in Lithuania. Since 2017 he has delivered 286+ projects and works remotely with clients across Lithuania.

## Key Focus Areas

- **WordPress**: websites on a custom theme built from scratch, without a page builder.
- **WooCommerce**: online stores, integrations, maintenance and speed fixes.
- **Laravel**: custom web applications and integrations.
- **Technical SEO & GEO**: schema.org markup, llms.txt and content structured for Google and AI search.

## About llms.txt Implementation

The llms.txt file is generated by Yoast SEO on the site's custom WordPress theme. It lists the main service pages and recent articles (in Lithuanian), so AI assistants can find services and practical guides without crawling the whole site.
