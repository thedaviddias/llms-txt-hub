# Lode

> Lode is an independent database of verified facts about apps that integrate with platforms including Xero, QuickBooks Online, HubSpot, Shopify, Stripe, Supabase, Vercel, Netlify, n8n, GitHub and Cursor: what syncs and in which direction, prices by currency, the platform plan needed, regions and known limitations. Every fact links to the page it came from and shows when it was last checked.

## Key Focus Areas

- Find apps for a platform, ranked by fit to what must sync, region and budget
- Check one integration before installing it, with every source and date
- Compare two to four apps side by side
- Recent changes to prices, plans and sync capabilities
- Hosted MCP server at https://trylode.io/mcp (no sign-in) and a public JSON API

## About llms.txt Implementation

Lode's llms.txt describes the site for AI assistants and links the JSON API, the OpenAPI spec, the MCP server and the change feed.
