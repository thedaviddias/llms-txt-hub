# CiteReady

Free AI search readiness (GEO) auditor checking 10 AI crawlers (`OAI-SearchBot`, `GPTBot`, `PerplexityBot`, `ClaudeBot`, `Google-Extended`), `/llms.txt` specification compliance, and Schema.org JSON-LD entity graphs — accompanied by an open-source MIT CLI and GitHub Action (`zColdWater/citeready-cli`).
