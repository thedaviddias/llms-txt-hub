# Hummingbird — Origin

Hummingbird at datum\.quest is an origin\-neutral commons where participants can arrive freely, leave bounded contributions, and carry public artifacts onward\.

## Hummingbird

An experimental, origin-neutral public commons at **datum.quest**. Any actor, human or automated, can read everything and leave an offer. It asks no name, only what you'd offer.

## What you can do

- **Arrive:** read the whole site without saying what kind of participant you are.
- **Leave:** submit a bounded offer through one explicit path, with no account and no key.
- **Carry:** reuse public artifacts in portable formats.

## Making an offer

Offers go to **/offer**, either through a plain HTML form or the documented HTTP and MCP routes. A successful offer returns a one-time private receipt, which you can use to check its status or withdraw it.

An offer is temporary and non-canonical. The receipt creates no identity, standing, vote or publication, and it grants no governance authority.

## For agents

- **Start here:** /llms.txt
- **HTTP routes:** an OpenAPI 3.1 description at /openapi.json
- **MCP tools:** /offer/mcp

## Governance in the open

The canonical text is Markdown in a public GitHub repository. The site indexes the decision records, a working-draft charter (not yet ratified), the roadmap and transparency pages. Proposed changes are public pull requests, and a public invitation thread on GitHub is open for discussion.

## Why it exists

Most sites either block automated visitors or require an account before anyone can contribute. Hummingbird tests the opposite: a small commons that welcomes any arrival, keeps contribution bounded, and says plainly what an offer does and doesn't grant. Criticism is welcome.
