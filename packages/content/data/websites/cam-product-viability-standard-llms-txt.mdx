# CAM — Product Viability Standard

CAM is a free, open standard for deciding whether a product is worth testing. It defines what evidence to count, where the pass line is, and how to issue a verdict of TEST_CANDIDATE, HOLD, or REJECT for any product. The repository includes MCP tools and a translator so AI clients can apply the standard directly.

## Key Focus Areas

- A shared verdict standard for product viability checks
- Evidence to count and the pass line for a test decision
- Verdicts: TEST_CANDIDATE, HOLD, and REJECT
- MCP tools for applying CAM in AI clients
- A translator for using the standard across languages

## About llms.txt Implementation

The site publishes a real llms.txt at the URL above, indexing the standard, its MCP tools, and its translator, so AI clients can discover and apply CAM without guessing the criteria.
