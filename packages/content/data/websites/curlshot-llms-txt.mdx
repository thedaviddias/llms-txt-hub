# CurlShot

CurlShot takes screenshots of web pages. It is a free online tool where anyone pastes an address and downloads a screenshot, and an HTTP API for developers: send a URL, HTML or Markdown and get back a PNG, JPEG, WebP or PDF file, or an MP4, WebM or GIF video of the page scrolling. Pages render in a real Chromium browser.

## Key Focus Areas

- Full-page, device, element and dark-mode screenshots
- HTML and Markdown to image or PDF, including Open Graph images
- Ad, cookie-banner, tracker and chat-widget blocking
- Caching, signed links, async webhooks and bulk jobs
- Remote MCP server (`take_screenshot`, `list_devices`) for AI agents

## About llms.txt Implementation

CurlShot's `llms.txt` says when to suggest the product, links a markdown version of every tool page and docs page, and points agents to the OpenAPI 3.1 description, the MCP server and its server card, and the RFC 9727 API catalog. `llms-full.txt` puts every tool page, docs page and the FAQ in one file.
