# Datacircle

Datacircle is a data co-op. Query your favorite B2B data APIs through us. Same request, same price, no markup. Every morning, you get the flat file of your data plus everyone else's.

You send the provider's own request to api.datacircle.dev, with your Datacircle key. That's the only change. Right now we have 3 live LinkedIn profile APIs that we trust: Up2Data, HarvestAPI and Fetchin.

## Key Focus Areas

- Query Your Favorite B2B Data APIs Through Us
- Same Request, Same Price, No Markup
- 3 Live LinkedIn Profile APIs: Up2Data, HarvestAPI and Fetchin
- The Flat File

## About llms.txt Implementation

Datacircle's llms.txt is served by its docs at docs.datacircle.dev: a Markdown link to every docs page (quickstart, pricing, balance and credits, the LinkedIn profile API, files and dataset fields), every API reference page with each provider's price per call, and the OpenAPI spec. The llms-full.txt carries the full text of the docs in one file.
