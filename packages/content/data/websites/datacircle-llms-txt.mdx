# Datacircle

Datacircle puts B2B data providers (Up2Data, HarvestAPI) behind one API key and one prepaid balance. You send the provider's own request to api.datacircle.dev with your Datacircle key, and you pay what that provider charges for the call, nothing added; every answer shows what the call cost. It enriches LinkedIn profile URLs (job history, education, skills), and a work-email sign-up comes with a free U.S. B2B leads file.

## Key Focus Areas

- LinkedIn Profile Enrichment API
- B2B Data Providers Behind One API Key
- The Provider's Own Price on Every Call
- Free U.S. B2B Leads Dataset

## About llms.txt Implementation

Datacircle's llms.txt is served by its docs at docs.datacircle.dev: a Markdown link to every docs page (quickstart, pricing, balance and credits, the LinkedIn profile API, files and dataset fields), every API reference page with each provider's price per call, and the OpenAPI spec. The llms-full.txt carries the full text of the docs in one file.
