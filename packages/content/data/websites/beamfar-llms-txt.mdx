# Beamfar

EU website monitoring, CISA KEV Exploit Watch, SSL/domain alerts, 8 free browser security tools, and a 16\-tool OAuth 2\.1 hosted MCP server\.

## Overview

Beamfar is an EU-hosted website monitoring and external security platform built by CRM LR S.R.L. (Romania). It verifies outages from multiple EU regions, tracks SSL/domain expiry, watches for CISA KEV vulnerabilities (Exploit Watch), and alerts on frontend secret leaks or lockfile CVEs.

- **Free (€0 permanently, no card):** 1 site, 5-min checks from 2 EU regions, public status page, read-only REST API & MCP.

- **Team (€59/mo):** 40 sites, 30s checks, webhooks, client portal.
- **Agency (€149/mo) / Agency Plus (€249/mo):** 100 / 200 sites, white-label reports, write-enabled MCP tools.
