# Warmerly

Warmerly is email warmup and cold outreach software. It warms up Gmail and Outlook mailboxes on a gradual ramp, then runs email, LinkedIn and WhatsApp campaigns from the same workspace.

The llms.txt file indexes the product documentation, the Help Center and the REST API reference, and llms-full.txt carries the whole documentation in one file. Each docs page is also available as Markdown at its own URL with a .md suffix. AI assistants can also act on a workspace through the MCP server described at https://docs.warmerly.com/ai.
