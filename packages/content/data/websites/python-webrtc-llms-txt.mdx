# Python WebRTC

Chrome's WebRTC engine \(libwebrtc M152\) with the W3C browser API, in Python and asyncio\. pip install wrtc\.

## What it is

Python WebRTC binds **libwebrtc M152**, the WebRTC engine inside Chrome, and exposes it through the W3C browser
APIs in asyncio: `RTCPeerConnection`, data channels, tracks, WebCodecs frames, encoded transforms and stats.
Install it with `pip install wrtc` and import it as `webrtc`.

## What the llms.txt covers

- **Start**: the quickstart, and migrating from aiortc by changing one import
- **Guides**: connections, data channels, events, media, H.264 and field trials
- **API reference**: every interface, dictionary, enum and exception, generated from the docstrings
- **Examples**: runnable programs from the repository
