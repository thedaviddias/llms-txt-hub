# Argus Mesh

Argus Mesh is a fraud detection and prevention platform for e-commerce, fintech, payments and digital banking teams. It scores transactions over a REST API in under 50ms on average and resolves devices, payment instruments, addresses and IPs into a graph, so coordinated fraud rings surface that single-transaction rules miss.

## Key Focus Areas

- Real-time transaction scoring and approve / step-up / block decisions
- Graph-based entity resolution for fraud ring and mule network detection
- Rule DSL and versioned decision flows with maker-checker approval
- API reference generated from a published OpenAPI spec
