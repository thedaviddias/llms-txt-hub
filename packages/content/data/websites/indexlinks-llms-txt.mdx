# IndexLinks

IndexLinks gets a website's new and updated pages crawled. It sends them to Bing, Yandex, Naver, Seznam and Yep through IndexNow, to Google through the site owner's Search Console, to Baidu, and to the AI crawlers (GPTBot, ClaudeBot, PerplexityBot), then shows a verified receipt for each crawler visit. It also has a free site check, a REST API and an MCP connector for Claude and ChatGPT.

## Key Focus Areas

- IndexNow and Search Console submission
- AI crawler discovery
- Verified crawl receipts
- Site crawlability checks
- API and MCP connector
