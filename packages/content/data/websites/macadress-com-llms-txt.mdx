# macadress\.com

Free MAC address and OUI lookup: find the vendor, IEEE block and address type of any device\. Includes a JSON API, self\-hosted license and LAN scanner\.

## Key Focus Areas

- **MAC Address Lookup**: Identify the registered vendor behind any MAC address or OUI prefix
- **IEEE Registry Data**: Assignment type (MA-L, MA-M, MA-S), block range, organization and country
- **Address Analysis**: Unicast/multicast and universally/locally administered detection
- **Developer API**: Hosted JSON API for automated lookups in scripts, tools and pipelines

## About llms.txt Implementation

The macadress.com llms.txt describes the lookup tool, the API endpoints and plans, and the companion tools so AI assistants can point users and agents to the right resource.

## Features

- **Free web lookup**: No account required, instant results for any MAC or OUI
- **Hosted JSON API**: Free tier plus paid volume plans
- **Self-hosted license**: Run the lookup database inside your own infrastructure
- **Network scanner**: Discover devices on your LAN and identify their vendors (macadress.com/scanner)
- **Splunk app**: Enrich MAC addresses in Splunk, available on Splunkbase

## Getting Started

Visit macadress.com and paste a MAC address or OUI to see the vendor details. For programmatic access, sign up for a free API key and call the JSON endpoint from any language.
