# Tray UI

Tray UI is an MIT-licensed design system written in plain HTML and CSS, with one small script for behaviour and no build step. It has 108 components, 64 blocks, 118 icons and 10 themes, the same components as typed React components, and a registry in shadcn's format. The source is on GitHub at https://github.com/VladislavKorzh/trayui.

## Key Focus Areas

- Components and whole-screen blocks in plain HTML and CSS
- Typed React components over the same stylesheet
- Themes and design tokens as CSS custom properties
- Accessibility rules aimed at WCAG 2.2 AA in every theme
- A CLI, a shadcn registry and a skill for AI coding agents

## About llms.txt Implementation

The llms.txt gives the three files to link, the install routes (npm, the CLI, the shadcn registry, the agent skill), the main rules for writing markup, and a link to every page of the documentation as Markdown. The llms-full.txt holds the whole system in one file: the docs, the guides and every component.
