# Digest AI

Digest AI is a free AI news site. It reads about 78 sources every 20 minutes, merges the outlets that report the same event into one story and links every source.

## Key Focus Areas

- AI news, one story per event with every source linked
- A daily five-story briefing and a spoken daily briefing
- Model release and funding trackers
- Practical AI notes for marketers and small businesses

## About llms.txt Implementation

Digest AI's llms.txt lists every section of the site, says how to cite a story, and points to each story as Markdown or JSON (add .md or .json to a story address) and to keyless JSON indexes of the latest stories, today's briefing and each category.
