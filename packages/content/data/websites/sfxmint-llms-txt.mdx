# SFXMint

Find CC0 sound effects for interface and game events through browser previews, a no-key library API or a remote MCP server. Audio is AI-generated or procedurally synthesized. Individual library downloads require no signup; ZIP downloads require a free account. Optional custom generation is separate and uses paid passes or plans.
