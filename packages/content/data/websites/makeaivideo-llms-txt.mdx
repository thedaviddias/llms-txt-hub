# MakeAIVideo

MakeAIVideo (makeaivideo.ai) is an AI video generator for TikTok, Instagram Reels and YouTube Shorts. It writes the script, generates each scene with AI video models or stock footage, adds an AI voiceover in 24 languages, captions and music, and renders an MP4. Videos can be posted or scheduled to connected social accounts. Developers can use the REST API, the SDK, the CLI or the hosted MCP server.

## Key Focus Areas

- Prompt, Script and Image to Video
- Talking Avatars and AI Voiceover
- Captions, Music and Social Posting
- REST API and MCP Server
