# jopp

jopp helps job seekers find jobs in Switzerland and prepare tailored CVs and cover letters, with a public, read\-only MCP endpoint\.

## About jopp

jopp helps job seekers describe their experience and goals, find suitable jobs, and prepare tailored application documents. The web interface is in German.

## Public access

Public job search and job details cover Switzerland and Liechtenstein. The read-only MCP endpoint at `https://getjopp.app/mcp` requires no account or API key.
