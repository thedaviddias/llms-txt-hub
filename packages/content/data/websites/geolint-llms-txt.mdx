# geolint

geolint audits websites for AI-search readiness: robots.txt evaluated across
51 known AI crawler tokens, llms.txt and AI manifests, structured data, and
content citability — 51 rules producing a 0–100 score with a concrete fix for
every finding. Ships as an npm CLI, a GitHub Action with sticky PR comments,
and an MCP server (`npx -y @iliasabk/geolint mcp`) so AI assistants can run
audits natively.
