# Dwellir

Dwellir provides blockchain RPC endpoints for 150+ networks, including Ethereum, Base, Polkadot, Solana, and Hyperliquid. The llms.txt covers plans and limits, API key authentication for HTTP, WebSocket, and gRPC, supported networks, and links to the API documentation. The llms-full.txt contains the full documentation, including method references for each chain and setup guides for the hosted MCP server at `https://mcp.dwellir.com/mcp`.
