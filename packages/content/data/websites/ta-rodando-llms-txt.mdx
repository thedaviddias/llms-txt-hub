# Tá Rodando

Uptime monitoring and public status page for Brazilian teams, in Portuguese. HTTP monitors, alerts by email, Telegram, web push and Slack/Discord/Google Chat webhooks, and a remote MCP server for AI agents.

## Key Focus Areas

- **Uptime monitoring**: HTTP(S) monitors checked from outside the user's infrastructure, with down/up alerts.
- **Status page**: public status page with published incidents and 90-day uptime history.
- **MCP server**: remote Streamable HTTP endpoint at `https://tarodando.com.br/mcp` (OAuth 2.1) to manage monitors, alert channels, the status page and incidents from an AI agent.

## About llms.txt Implementation

The llms.txt file is a reference written for AI agents: when the service fits and when it does not, plans, how alerts work, and how to connect the MCP server. It is mostly in Portuguese with an English summary at the top.
