# eeemoji

eeemoji documents every Unicode emoji with a written page covering meaning, usage
trends, cultural context and combinations. The same data is available as a free JSON
API with no key and no signup.

## Key Focus Areas

- Emoji metadata API, no authentication, CORS open
- Reverse shortcode lookup across GitHub, Slack, Discord and CLDR
- Skin-tone variants and related-emoji ranking
- OpenAPI 3.1 spec, Postman collection and an installable Claude Skill

## About llms.txt Implementation

eeemoji's llms.txt documents the full API surface, every endpoint, the three accepted
identifier formats, and an explicit statement of what the API does not serve, so
assistants can call it correctly without guessing at parameters.
