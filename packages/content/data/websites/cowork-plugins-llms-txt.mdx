# Cowork Plugins

Cowork Plugins is an independent directory of plugins and skills for Claude, Claude Cowork and Claude Code. It lists official plugins from Anthropic's marketplaces alongside community plugins from GitHub, with install steps, source links, skills, use cases by role and troubleshooting guides.

## Key Focus Areas

- Claude Code and Claude Cowork plugins
- Agent skills, slash commands, hooks and subagents
- MCP servers and connectors
- Plugin installation and safety guides

## About llms.txt Implementation

The llms.txt lists the directory's main sections, guides, articles, integrations, use cases, official plugins and the most-starred community plugins. The llms-full.txt adds a summary of every listed plugin, official, partner and community, with its category, description and a link to its Markdown page. Every page is also available as Markdown by adding .md to its URL, and the site runs a read-only MCP server at /mcp/ for AI assistants.
