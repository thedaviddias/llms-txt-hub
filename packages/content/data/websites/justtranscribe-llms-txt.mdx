# JustTranscribe

Turn audio, video and public links (YouTube, TikTok, Instagram, Google Drive) into accurate, timestamped text in 59 languages, with speaker labels, translation and Word, SRT or PDF export.

## Key Focus Areas

- Plans, limits and supported file types
- Tool pages for each job (voice notes, classes, meetings, interviews, YouTube and TikTok links)
- REST API, MCP server and integrations (ChatGPT, Claude, Zapier, n8n, Chrome)
