# Mnemoverse

Hosted AI agent memory that learns from outcomes, with shared rooms, in Claude, Cursor and ChatGPT\.

## About Mnemoverse

Hosted persistent memory for AI agents over MCP. Tell it a recalled memory helped or misled, and it re-ranks what comes back next. Shared rooms for multi-agent work. One key or OAuth across Claude Code, Cursor, VS Code and ChatGPT.

## llms.txt

The llms.txt and llms-full.txt files at the site root describe the Mnemoverse documentation for language models.

## Getting started

- Remote MCP endpoint: `https://mcp.mnemoverse.com/mcp,` with OAuth sign-in in the browser
- npm package: @mnemoverse/mcp-memory-server (MIT)
- Python SDK: mnemoverse on PyPI (MIT)
- Docs: `https://mnemoverse.com/docs`
