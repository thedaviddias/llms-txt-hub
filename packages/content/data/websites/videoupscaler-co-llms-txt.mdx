# VideoUpscaler.co

VideoUpscaler.co is an online AI video upscaler that upgrades low-resolution, blurry, or compressed videos to 1080p Full HD, 2K (1440p), and 4K (2160p) on cloud GPUs in the browser while preserving original audio, alongside a developer REST API, remote MCP server, and macOS desktop app.

## Key Focus Areas

- **Cloud AI Video Super-Resolution**: Multi-frame temporal video enhancement up to 4K (2160p) for real-world footage and anime/2D animation.
- **REST API & Remote MCP Server**: Programmatic video upscaling endpoints (`https://videoupscaler.co/api/v1`) and Model Context Protocol integration (`https://videoupscaler.co/api/mcp`).
- **Browser & Desktop Workflows**: Zero-install web studio plus native Apple Silicon desktop processing.
