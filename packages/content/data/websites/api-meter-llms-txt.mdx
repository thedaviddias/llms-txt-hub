# API Meter

API Meter is per-customer API usage analytics for small API teams. Point clients at an edge reverse proxy (change one base URL, no SDK) or POST batched events from your own server, then see requests, errors and p95 latency per customer, endpoint and plan, with a billing-ready monthly CSV export.

## Key Focus Areas

- Per-customer API usage analytics
- Usage-based billing exports
- Remote MCP server (Streamable HTTP) for AI agents
- OpenAPI 3.1 spec for machine clients

## About llms.txt Implementation

The llms.txt lists every endpoint (MCP, signup, stats, proxy, ingest, export) with auth rules, pricing and limits, and links the docs, integration guide and OpenAPI spec. The llms-full.txt inlines the full docs, integration guide and privacy text.
