# Xray Flow

Privacy-first documentation, visualization, and security auditing for Make.com, Zapier, and n8n automation workflows. Xray Flow connects to your automation accounts via API/OAuth or direct workflow JSON uploads, normalizes your blueprints, and turns them into professional, human-readable documentation — interactive flowcharts, as-built PDFs, security audits, and compliance reports.

## Key Focus Areas

- Automation workflow documentation (Make.com, Zapier, n8n, Power Automate, Microsoft Fabric import)
- Security auditing (API key exposure, leaked secrets, unhandled failure branches)
- Data lineage and PII visualization
- Workflow migration between platforms
- Client-side (WebAssembly) blueprint processing — privacy-first data handling

## About llms.txt Implementation

Xray Flow provides an `llms.txt` file with AI-readable information about its product, public tools, documentation surfaces, and data-handling model, plus an extended `llms-full.txt`.
