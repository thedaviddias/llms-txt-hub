# TariffMonkee: Pay

Small, single\-purpose web data APIs that AI agents pay for per call in USDC over the x402 protocol \(HTTP 402\)\. No accounts, no API keys, no subscriptions\.

## What it is

TariffMonkee is a set of small, single-purpose web data APIs that AI agents pay for per call in USDC over the x402 protocol. Every paid endpoint answers with HTTP 402 and its exact price. Any x402 v2 client can pay and get the result in seconds. There are no accounts, no API keys and no subscriptions.

## What agents can do with it

- Read the web: convert a URL to clean Markdown, screenshot or PDF a page, run a web search, or build a research bundle of up to 10 sources.
- Extract data: pull structured JSON from text or a URL using a schema you supply.
- Check trust and safety: URL safety verdicts, domain security grades, domain registration data, email deliverability, and a combined trust audit.
- Check local visibility: Google Business Profile audits, keyword rankings, AI answer visibility, and lead lists.

Prices run from $0.001 to $0.75 per call.
