# DeFi Garden

DeFi Garden is an open-source, zero-backend DeFi yield intelligence engine and goal-based planner with an official Model Context Protocol (MCP) server. Built for cautious savers, DeFi operators, and autonomous AI agents who value mathematical honesty over speculative hype.

## Key Focus Areas

- **Predictive Underwriting**: DeFi Scores, 14-day yield forecasts, and pool risk breakdown across Base, Ethereum, and Arbitrum.
- **Deterministic Trust Rails**: 1000% APY sanity ceiling, $100K TVL liquidity floor, and dual-oracle divergence guards to eliminate rate hallucinations.
- **Machine-Native MCP API**: Streamable HTTP endpoint (`/api/mcp`) exposing tools for pool discovery (`find_pools`), single-pool auditing (`get_pool`), and bill-coverage lump sums (`forever_number`).
- **Goal Planner**: Calculate capital required to cover recurring expenses forever using live blended yield.

## About llms.txt Implementation

DeFi Garden serves `/llms.txt` and `/llms-full.txt` natively, providing complete machine-readable context, protocol documentation, trust rail specifications, and structured endpoint catalogs for LLM agents.
