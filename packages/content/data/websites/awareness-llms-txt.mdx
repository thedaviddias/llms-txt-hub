# Awareness

Awareness gives AI coding agents persistent memory across sessions. It stores decisions, fixes, workflows and preferences as structured knowledge cards and recalls the relevant few on demand — so the active context window stays small and stable instead of growing until the session stalls.

- **Local-first, offline, no account** — memory is plain Markdown plus a SQLite index on your machine.
- **Hybrid retrieval with zero LLM calls on the retrieval side** (FTS5 + embeddings + knowledge graph).
- **96.0% Recall@5 on LongMemEval**, measured through the real local-daemon pipeline and reproducible in-repo.
- **Integrations**: native OpenCode plugin (`@awareness.market/opencode-plugin`), Claude Code skills, OpenClaw plugin, and MCP for 13+ IDEs; Python & TypeScript SDKs with zero-code interceptors.
- Apache-2.0. Repos: https://github.com/everest-an/Awareness-SDK · https://github.com/everest-an/Awareness-Market
