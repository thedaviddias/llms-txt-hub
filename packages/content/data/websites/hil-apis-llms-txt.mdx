# HIL APIs

HIL APIs is an invite-only human-in-the-loop API that helps companies add reviewed human judgment to AI workflows.

## Key Focus Areas

- AI output review and verification
- Research and classification
- Translation and multilingual judgment
- Structured human feedback for agent workflows

## About llms.txt Implementation

HIL APIs publishes both `llms.txt` and `llms-full.txt`, plus machine-readable agent discovery routes for its public product and application flows.
