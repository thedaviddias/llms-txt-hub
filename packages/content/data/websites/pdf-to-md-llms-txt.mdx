# PDF to MD

PDF to MD converts text PDFs, Word documents, and HTML into Markdown with free browser-local processing. Local conversion does not upload file contents. Optional cloud conversion and OCR support scanned PDFs and images using account allowances or credits.

The developer documentation covers the REST API, remote MCP integration, conversion jobs, and Python and JavaScript client examples.
