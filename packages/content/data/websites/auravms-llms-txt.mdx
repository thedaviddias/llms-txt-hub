# AuraVMS

AuraVMS is procurement software for small and mid-size teams. Buyers send requests for quotation to their suppliers, suppliers reply through a simple link without an account, and AuraVMS lines the quotes up side by side so the buyer can place a purchase order. It also has a public API and a remote MCP connector for Claude and ChatGPT.

## Key Focus Areas

- Supplier management
- Requests for quotation (RFQs)
- Quote comparison
- Purchase orders
- Procurement API and MCP connector
