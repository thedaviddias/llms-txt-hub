# Social Fetch

Social Fetch is a pay as you go API for public social media data. It returns profiles, posts, comments, transcripts and search results as JSON. AI agents can connect through a hosted MCP server, and the public repo also has a local stdio server.

## Key Focus Areas

- Public social media data as JSON
- Hosted MCP server with OAuth or an API key
- Local stdio server for clients that only run local servers

## About llms.txt Implementation

Social Fetch publishes llms.txt and llms-full.txt with AI readable documentation for the API and the MCP integration.
