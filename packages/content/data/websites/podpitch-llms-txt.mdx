# PodPitch

PodPitch helps PR teams, founders and marketers find relevant podcasts, create personalized pitches and manage outreach from their own email. Public podcast discovery is also available through a hosted MCP server without a PodPitch account. Existing customers can authorize private campaign, draft and inbox tools separately.
