# ETFIQ

ETFIQ is a free, independent research site for US-listed ETFs\. Every number carries its source and as-of date\.

## Key Focus Areas

- **ETF data**: holdings, fees, fund flows and returns against each fund's own benchmark, recomputed nightly.
- **Machine-readable twins**: every page has a .json or .md twin at the same address, and the data files are open at https://etfiq.com/data/.
- **MCP server**: a remote MCP server at https://mcp.etfiq.com with no key needed.

## About llms.txt Implementation

Our llms.txt lists the site's sections, data files and twins so assistants can find the right page and cite it with its date.
