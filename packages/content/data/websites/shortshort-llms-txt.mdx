# shortshort

Turns one long talk or podcast into vertical 9:16 shorts that end on a complete sentence, with the crop following the speaker and captions timed word by word.

## About llms.txt Implementation

shortshort provides both `llms.txt` and `llms-full.txt`. Both files are generated from the same source as the site pages, so they stay in step with the site rather than being a one-off snapshot.
