# Amo\.ng

Amo\.ng offers public AI prompts, workflows, skills and professional packs to help people turn AI into practical work\.

## About Amo.ng

Amo.ng helps professionals turn AI into practical work through a public library of structured prompts, guided workflows, reusable skills and professional resources.

## Key features

- **Prompts:** Task-focused instructions with clear inputs, constraints and expected outputs.
- **Workflows:** Ordered steps for completing more complex tasks.
- **Skills:** Reusable instructions for recurring activities.
- **Professional Packs:** Curated resources, templates and practice cases.
- **Topics:** Collections organised around related areas of work.

## Access for AI assistants

Amo.ng provides an API and a read-only MCP integration for discovering and retrieving published resources. These interfaces do not execute tasks, store provider API keys or certify professional conclusions.
