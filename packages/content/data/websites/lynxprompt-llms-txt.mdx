# LynxPrompt

LynxPrompt is a self-hosted web app and CLI that turns one set of AI coding rules into the file each tool reads: AGENTS.md, CLAUDE.md, .cursor/rules, Copilot instructions and more, 30 rule-file formats in all, plus slash commands for six of them. A wizard writes the rules from your stack, and blueprints with placeholders let one set fit many projects.

## About llms.txt Implementation

LynxPrompt's llms.txt summarises the platform and links its getting-started, wizard, blueprints, CLI, API and platforms documentation. The llms-full.txt puts the supported platforms, features, CLI reference and quick start in one file.
